## 二、资源库检索

### 2.1 搜索与快捷筛选的关系

- 搜索和左侧快捷筛选是两个同级、独立功能，不把快捷筛选称为搜索的第二层。
- 用户可以只使用搜索、只使用快捷筛选，也可以同时使用。
- 同时使用时采用交集（AND）关系，只展示同时满足全部条件的资源。
- 清除搜索不得清除快捷筛选；清除快捷筛选也不得清除搜索。
- 搜索、快捷筛选、精确筛选和目录条件均需清晰展示，并能单独清除。

### 2.2 弹窗布局

- 左侧设置固定快捷筛选栏，支持层级逐步展开并独立滚动。
- 右侧上方只保留搜索框，以及系列、颜色、语言三个精确筛选。
- 右侧主体只展示资源结果。
- 系列与左侧年级不自动同步；两者同时选择时继续按交集筛选。

### 2.3 左侧快捷筛选

快捷筛选必须先选年级，年级固定为：

- S3–S7
- S8
- S9
- S10

年级筛选结果同时包含：

- 当前年级专属资源；
- 覆盖当前年级的跨年级资源；
- 未标年级的通用资源。

选择年级后显示已有快捷标签。现有标签全部保留，并按以下分组组织：

- 教学内容
- 流程导航
- 媒体书写
- 编辑工具
- 基础框体
- 素材资源

展示规则：

- 教学内容默认展开，其余分组默认折叠。
- 点亮一下、方法小结、科普、讨论一下排列在教学内容前部。
- 第二层标签单选；再次点击已选标签可以清除。
- 年级始终可见，后续层级在同一列向下展开，不切换成另一页。
- 左侧筛选栏独立滚动，不占用右侧结果区的滚动空间。

四个特殊标签具有第三层筛选。选择其中任意一个后，在标签下方显示：

- 全部（默认）
- 入口控件
- 二级弹窗

第三层为单选。

### 2.4 默认状态与目录兜底

- 打开资源库时不自动选择或记忆年级，也不加载全量资源。
- 默认提示：“输入关键词搜索，或先选择左侧年级”。
- 目录不直接占用资源检索页，在弹窗右上角通过“更多 → 按目录浏览”进入。
- 目录使用独立窗口，只负责路径选择，不重复展示资源列表。
- 确认目录后关闭目录窗口，回到主资源结果，并增加可清除的“目录：……”条件。
- 返回时保留之前的搜索、快捷筛选和精确筛选状态。
- 后续补齐可能遗漏的通用背景图及相关标签。

### 2.5 实施时的资源确认

领取 #73 后，开始实现前向开发者及资源维护方索要并确认：

- 正式资源库快照和版本；
- 年级、系列、颜色、语言、快捷标签与目录的完整映射；
- 遗漏的通用背景图和新增标签资料；
- 新版界面素材或设计标注（如有）。

资源不齐时可以先完成布局、状态和筛选逻辑，但不得猜测资源归属；待补项必须记录在 PR 中。

## 三、锁定图层的画布行为

### 3.1 最终交互规则

- 被锁定图层完全不参与画布点击命中。
- 点击锁定图层覆盖区域时，应继续向下查找并选中可命中的未锁定图层。
- 如果该位置只有锁定图层，则按点击画布空白处理。
- “当前已选元素优先”只适用于未锁定元素；元素自身锁定或受父级锁定后必须立即退出命中候选。
- 运行容器的画布线框和名称不能绕过锁定规则；锁定后点击这些入口同样继续向下命中或按空白处理。
- 锁定图层仍可通过图层列表选中、查看属性和解除锁定。
- 父级锁定只对其子树继承，不影响其他无关图层。
- 图层顺序、父子层级或选中状态变化后，视觉层级和点击命中层级必须保持同步。

### 3.2 排查与回归边界

实现 #75 时至少检查：

- 锁定元素是否仍进入画布命中候选；
- “当前已选元素优先”是否让已锁定的大图层持续截获点击；
- 嵌套容器与图层重排后，视觉顺序和实际命中顺序是否一致；
- 自身锁定、父级继承锁定与点击状态是否同步更新。

需要覆盖普通元素、按钮、重叠元素、嵌套元素、父级锁定、图层重排，以及“先选中后锁定”的场景。

## 四、键盘与分数输入

### 4.1 数字与小数点键盘

- 作为现有键盘选择器中的新增预设，不替换旧预设，也不改变现有默认键盘。
- 按键包含 0–9、小数点和删除。
- 不包含正负号、加减乘除或括号。
- 一个输入值最多出现一个小数点。
- 首次点击小数点时输入 `0.`。
- 输入过程中允许暂时保留末尾小数点，例如 `12.`。

### 4.2 分数输入键盘与分数输入框

- 新增可见的“分数输入框”组件；普通输入框不负责分数结构的渲染。
- 分数键盘包含 0–9、分数按钮和删除。
- 点击分数按钮后插入带横线的分子框和分母框，并自动聚焦分子。
- 一个外框内允许多个分数，也允许普通数字和分数结构混排。
- 一个分数结构固定占外框 3 个逻辑字符位；一个普通数字占 1 个字符位。
- 外框最大字符数由老师设置。
- 外框变大或变小时，最大字符数不变；字符位、分数结构和字号随外框尺寸自适应缩放。
- 分子和分母各自最多输入 4 位数字，内部数字不再重复占用外框字符位。
- 分子和分母是叶子输入格，只允许输入数字和删除，不允许再次插入分数结构。
- 分子达到 4 位后不自动跳到分母，由用户手动点击切换。
- 当前编辑的分子或分母必须有明确高亮。

删除规则：

- 当前分子或分母有内容时，删除最后一位数字。
- 分子和分母都为空时，再次删除会移除整个分数结构。
- 光标位于分数外时，删除最后一个普通数字或最后一个完整分数结构。
- 不提供单独的悬浮删除按钮。

### 4.3 绑定和答案配置

- 数字与小数点键盘绑定兼容的普通输入框。
- 分数键盘只绑定分数输入框；绑定列表需要过滤不兼容目标。
- 新增分数输入框时，如果页面已有分数键盘则自动绑定。
- 页面没有分数键盘时，打开键盘选择并创建、绑定分数键盘。
- 用户取消选择时保留分数输入框，显示明确的未绑定提示，并允许之后重新绑定。
- 绑定键盘时扫描当前页面全部 `KlBaseKeyboard`，兼容历史课件中没有 `_keyboardPreset.id` 的旧版/自定义键盘；选择已有键盘后同时补齐键盘和输入框的同一 `camp`。
- 新增输入框优先复用当前页面已有兼容键盘；仅在没有可用键盘时才通过预设选择创建并绑定，避免重复创建。
- 分数正确答案通过属性面板中的“设置正确答案”进入同一套可视化分数编辑器，不向老师暴露内部编码。
- 分数按结构和内容精确判断；`1/2` 与 `2/4` 不自动视为等价。
- 分数输入框外框沿用普通输入框资源和九宫格规则，调整宽度时不得拉伸圆角和边缘。
- 分数输入框的位图字体必须按素材实际字符表逐格映射；点击数字或运算符时只显示对应字符，不能把整段字体素材误绘制到输入框中。内容宽度按真实字符单元计算，普通字符的布局宽度必须与实际字体缩放和字间距一致，并始终缩放在外框内容区域内。

### 4.4 非本期范围与资源索取

数字、分数、加减乘除、括号和小数点组合的“数学表达式键盘”作为后续独立键盘，不进入 #74。

领取 #74 后，在开始视觉实现前向开发者索要：

- 数字与小数点键盘资源图；
- 分数键盘、分数按钮和分数输入框资源图；
- 普通、按下、选中、禁用等状态资源；
- 原始尺寸、拉伸或九宫格规则及字号规范。

资源暂缺时可以先完成数据、输入、绑定、导出和测试，不能自行定稿最终视觉。

2026-07-21 实施前资源确认结果：

- 数字、小数点、删除、分数按钮、分数线、键盘外框及普通/按下字形均复用已确认的旧课件键盘资源，并按内置运行资源注册，不依赖用户本机路径。
- 分数按钮图标必须跟随当前键盘主题和按键状态配色：黄色主题使用 `img_fraction3.png` / `img_fraction4.png`，蓝色主题使用 `img_fraction5.png` / `img_fraction6.png`，绿色主题使用 `img_fraction7.png` / `img_fraction8.png`，每组依次为普通态和按下态。v1.2.0 当前只启用黄色主题，因此编辑器、预览、导出和选择器缩略图统一使用黄色组，不在本次增加主题切换入口。
- 分数输入框外框复用现有输入框的普通、聚焦和错误三态皮肤，保持普通输入框与分数输入框的题目视觉一致。
- 键盘禁用态不增加独立切图，统一使用普通态降低透明度并去饱和；禁用时不响应输入。
- 分子或分母的当前编辑高亮由运行状态动态呈现，不把高亮状态固化进答案数据。
- 键盘选择器缩略图由正式键盘组合生成，不要求美术额外提供整张预览图。
- 旧资源中用于幂和复杂表达式的素材不进入本 Issue；不得借复用资源扩大为数学表达式键盘。

2026-07-21 追加键盘视觉资源确认：新版资源目录提供黄色、蓝色、绿色三套完整键盘皮肤，以及 SDK 中对应的 `KeyBoard41UI` 原始布局。#74 第一版默认使用黄色主题，底板按 `img_jpk.png` 的 `330×420` 九宫格规则绘制，按键采用 3 列 4 行布局；蓝色、绿色主题暂不进入本版。

## 五、输入答案与两框算式关系

### 5.1 单框多候选答案

- 一个普通输入框或分数输入框可以配置一个或多个候选正确答案，任一候选匹配即可（OR）。
- 普通答案支持用逗号、分号或回车分隔，保存后以答案标签展示；分数答案继续使用可视化编辑器逐个管理，不暴露内部编码。
- 独立输入框使用自身候选答案判定；嵌套在答题判定容器内但未参加算式关系的输入框，由父级容器统一收集候选答案并做 AND 聚合。`KlInputBox` 默认就是答题判定容器；普通 `ContainerBox` 默认只负责布局，必须由老师显式开启“启用答题判定”后才承担该职责。
- 输入键盘和正确答案是两层配置：键盘决定能输入什么，候选答案决定哪些独立输入结果正确。

### 5.2 两框算式关系

- 第一版一条关系只连接同一个答题判定容器内的两个输入框，一个输入框最多参与一条关系。答题判定容器包括 `KlInputBox`，以及显式开启“启用答题判定”的 `ContainerBox`。
- 支持加、减、乘、除和两框相等。加、减、乘、除配置目标结果，例如 `A × B = 4`；相等直接判断 `A = B`。
- 判定读取两个输入框的当前数值并动态计算，不使用候选答案笛卡尔积、答案排重或完整答案方案枚举。
- 数值类型由输入框能力决定。允许小数时，`0.5 × 8 = 4` 与 `8 × 0.5 = 4` 都正确；分数也按数值参与关系计算。
- 小数比较使用稳定容差，避免常见浮点误差；除数为零、无法解析为数值或关系配置不完整时不能判为正确。

### 5.3 配置边界

- 选中输入框时直接管理候选答案；答题判定容器内的输入框还可以发起关系，选择同容器内另一个可用输入框、运算符和目标结果。
- 关系选择器、关系卡片、父容器概览和校验提示统一显示用户设置的图层名称；底层仍使用稳定 ID 维持引用，图层重命名后显示必须实时更新且关系不能断开。
- 建立关系后，两个输入框都显示同一关系卡片并直接编辑父容器保存的同一份关系数据，不再同时展示独立答案编辑，避免双重判定来源。
- 父级答题判定容器显示关系概览和未关联空位状态，负责集中检查；输入框属性负责就地快速编辑。
- `ContainerBox` 的开关关闭时保留已有候选答案和关系配置，但停止把该容器作为统一判定目标；容器内输入框恢复按独立输入框规则判定。再次开启后恢复原有组内配置。
- 输入框只归属离自身最近的答题判定容器；嵌套答题容器不会把内层输入框重复纳入外层判定，也不允许跨答题判定容器建立关系。
- 输入为空时整题返回未完成；未关联空位按候选答案判定，每条关系按算式判定，全部结果均正确时整题才正确。
- 删除、改名、排序、复制页面或内部页面后，输入引用必须保持稳定；失效引用、重复占用、无效目标结果或空位没有判定规则时显示可修复提示并阻止预览与发布。
- 确定按钮引用的答题容器被删除或替换后必须保留断链并明确显示“目标已失效”，不得在下拉框中伪装成同名或第一个可用容器；修复前阻止预览与发布。
- `ContainerBox` 的确定按钮必须直接读取统一 `isRight()` / `isNull()` 三态结果并执行默认反馈与锁屏，不得调用依赖 `getWrongIdx()` 等能力的 `KlInputBox` 专用确认逻辑。
- 历史 `_judgeAnswer` 和 `KlInputBox.answer` 保持读取兼容。本次不支持三个以上输入框的复合表达式、括号、自定义公式、一个输入框参与多条关系或跨答题判定容器建立关系。

## 六、选择题组件

### 6.1 老师端配置

- 不再提供手动“单选题 / 多选题”开关。正确答案为 1 个时自动判定为单选题，达到 2 个及以上时自动判定为多选题；右侧只读显示“尚未配置 / 单选题 / 多选题”。
- 每个选项是一个独立的可选择图片元素，老师可以替换选项框体资源并在其上方叠放文本。文本只负责展示，学生点击文字区域时穿透到下方选项元素。
- 正确答案区域使用可增删的下拉列表。候选只包含当前选择题容器直属的选项元素，不搜索页面或全局元素，也不包含题目文本、背景和装饰图片。
- 下拉框显示选项的图层名称，内部保存稳定元素 ID；选项改名后答案引用不失效，显示名称自动更新。
- 已设为正确答案的元素不再出现在其他答案下拉框中，避免重复添加。
- 删除已设为正确答案的选项时，同步移除答案引用、重新推导题型并明确提示；撤销操作可以完整恢复选项和答案。

配置异常：

- 草稿阶段允许暂时没有选项、只有一个选项或没有正确答案。
- 预览或发布时，每个选择题至少需要两个选项、至少一个正确答案，且全部答案引用必须有效；不满足时明确提示并阻止继续。
- 选择题尚未投入老师制作，本期直接切换到稳定元素引用，不承担历史课件迁移或双轨兼容。

### 6.2 学生端交互与判定

- 点击选项只记录当前选择，不立即判断。
- 单选题始终最多选择一个选项；点击新选项自动替换之前的选择，再次点击当前选项可以取消。
- 多选题不根据正确答案数量限制学生勾选数量，避免泄露答案数量。
- 多选结果必须与正确答案集合完全一致，不能漏选或多选。
- 正课与预习由画布内确认按钮触发判定；线上作业和专题测评复用 SDK 右上角“完成”按钮提交，不额外生成确认按钮。“修改”按钮清空当前选择和结果后重新作答。
- 线上作业未选择任何答案时点击“完成”，继续显示现有跳过确认；确认跳过后按错误提交。
- 正课判定正确后锁定本题；判定错误后允许继续修改，再次点击选项时先清除结果状态。

例如正确答案为 A、C：

- 选择 A、C：正确。
- 只选择 A：错误。
- 选择 A、C、D：错误。

### 6.3 视觉与状态规则

- 通常态使用 `237×77` 青绿色底框；鼠标或手指按住期间临时替换为同尺寸橙色底框。
- 松开后，已选项在通常底框上显示 `259×99` 黄色发光描边；取消选择时移除描边。
- 判定结果替换黄色选中描边，不与其叠加：整题正确时已选项显示 `251×91` 绿色描边，整题错误时所有已选项显示同尺寸红色描边。
- 多选整体判错时不单独区分已选项中哪些局部正确，也不主动揭示漏选的正确答案。
- 错误后再次修改选择时清除全部结果描边，根据最新选择恢复黄色选中描边；线上作业点击“修改”时清空选择和结果。
- 选项默认尺寸为 `237×77`，只允许横向调整，高度保持不变。底框使用九宫格横向拉伸，选中、正确和错误描边同步宽度并分别保持向外扩展 `11px`、`7px`、`7px`。
