# 第一阶段：内部界面管理系统 MVP

> 更新日期：2026-07-09
> 用途：记录阶段一 MVP 的交互目标、模板入口、页面管理规则、复制复用边界和验收标准。

## 一、定位

阶段一不再做方案对比，正式收敛到方案 A：在一个小关卡内部提供“内部界面管理器”。

它不是新的多关卡流程，也不直接复用现有 `subPage`。它的定位是当前小关卡内的功能页面与事件管理能力，帮助老师管理：

- 主界面：当前小关卡的默认入口，承载题干、主要按钮和基础内容。
- 同级界面：题内分页或内容切换，例如第 1 题、第 2 题、第 3 题。
- 弹窗界面：由按钮打开的遮罩叠层内容，例如提示弹窗、解析弹窗。
- 事件关系：按钮打开弹窗、分页按钮切换同级界面、关闭按钮关闭弹窗。

阶段一 MVP 只做可测试交互原型和实施文档，不改真实编辑器代码、导出逻辑或后端接口。

## 二、为什么不能直接复用现有小关卡

当前项目里，课程结构大致是：

- `stage`：大关卡。
- `subPage`：小关卡。
- `elements`：当前小关卡里的组件。

现有导出会把一个 `stage` 下的多个 `subPage` 导出成 GameLoader 识别的 `subviews`。如果把弹窗、同级页面直接塞进 `subPage`，运行时会把它们理解成课件流程步骤，而不是当前题内的功能状态。

因此，新增内部界面管理必须遵守：

- 小关卡仍然是导出边界。
- 内部界面只属于当前小关卡。
- 内部界面不直接改变现有 `subPages -> subviews` 语义。
- 新能力先由新增模板 ID 隔离启用，避免影响旧课件。

## 三、MVP 主流程

MVP 原型要覆盖完整闭环：

1. 老师点击“添加大关卡”。
2. 打开模板弹窗。
3. 在“预设模板”第一张卡选择“内部界面管理模板”。
4. 创建一个包含默认主界面的小关卡。
5. 进入小关卡后，默认只显示主界面。
6. 老师通过当前列表里的箭头入口展开内部结构区。
7. 在结构区里新增同级界面或弹窗界面。
8. 老师可以切换、删除、复制、粘贴内部界面。
9. 右侧仍然是组件属性和事件设置。
10. 通过原型验证漏掉的交互和后续需求。

## 四、模板入口

新增的内部界面管理能力通过模板 ID 启用。

MVP 原型中，这个入口放在“添加大关卡”的模板弹窗里：

- 位置：预设模板 tab 第一张推荐卡。
- 名称：内部界面管理模板。
- 含义：创建一个启用了内部界面管理器的小关卡。
- 默认内容：只有一个主界面，结构区默认收起。

这样做的原因：

- 贴合当前编辑器已有的“从模板创建关卡”路径。
- 不需要额外发明一个新入口。
- 可以和普通空白关卡、视频关卡、自定义模板区分开。
- 后续真实实现时可以通过模板 ID 做能力隔离。

## 五、左侧交互结构

MVP 原型左侧模拟真实编辑器的关卡列表，但不再把内部结构做成正式课件流程里的下一步。

左侧分两层：

- 大关卡 / 小关卡列表：模拟现有编辑器已有能力。
- 当前小关卡内部结构：只在启用内部界面管理模板后出现。

当只有主界面时：

- 不直接展开完整结构区。
- 在当前小关卡列表内显示一个 PS 风格箭头/图标。
- 点击箭头后，展开内部结构管理区。

展开后：

- 主界面固定存在，不可删除。
- 同级界面可以新增、删除、复制、粘贴。
- 弹窗界面可以新增、删除、复制、粘贴。
- 节点上显示类型、状态和事件绑定情况。

## 六、右侧属性区边界

右侧必须继续保留给组件属性和事件设置。

阶段一不在右侧放：

- 结构树。
- 单独的事件关系图。
- 蓝图视图。
- 内部页面管理入口。

右侧只表达当前选中对象的属性，例如：

- 选中组件。
- 所属内部界面。
- 位置大小。
- 显示状态。
- 事件入口。
- 待重新绑定提示。

## 七、同级界面规则

同级界面是题内内容切换，不是弹窗。

表现规则：

- 点击分页按钮后，画布内容直接切换。
- 不出现黑色遮罩。
- 不出现弹窗浮层。
- 不需要关闭按钮回到主界面。
- 它仍属于当前小关卡，不是正式下一关。

典型例子：

- 第 1 题。
- 第 2 题。
- 第 3 题。
- 同一个小关卡内的补充页面。

## 八、弹窗界面规则

弹窗界面是遮罩叠层。

表现规则：

- 基于主界面生成不可选底板背景。
- 在底板上覆盖半透明遮罩。
- 用户只编辑遮罩上方的弹窗内容。
- 关闭按钮关闭弹窗，回到主界面状态。
- 弹窗底板是派生渲染，不属于常规组件。

现阶段弹窗模板缺少正式美术支持，所以 MVP 先验证底层能力：

- 主界面底板是否能表达上下文。
- 遮罩是否让老师理解当前在编辑弹窗。
- 弹窗内容是否能独立添加和管理组件。

## 九、复制复用规则

内部页面复制不能直接套用普通组件复制逻辑。

复制内部页面时，只复制：

- 页面类型。
- 用户添加的组件。
- 用户配置的可迁移资源。
- 页面内可匹配的事件关系。

不复制：

- 弹窗派生底板背景。
- 目标小关卡已有的主界面。
- 不属于复制范围的外部事件目标。
- 旧页面里的临时渲染状态。

粘贴规则：

- 只允许完整粘贴到同模板 ID 的内部界面管理器中。
- 粘贴到普通关卡时，显示不兼容提示。
- 粘贴到弹窗目标时，目标弹窗底板由目标主界面重新生成。
- 事件目标能自动匹配时重写 ID。
- 找不到目标时标记为“待重新绑定”，不静默保留旧引用。

## 十、MVP 验收标准

原型需要支持以下路径：

- 添加大关卡，并选择“内部界面管理模板”。
- 创建后默认进入只有主界面的状态。
- 通过箭头展开内部结构区。
- 新增同级界面，并确认它是内容切换，不是弹窗。
- 新增弹窗，并确认它有底板、遮罩和上层内容。
- 删除同级界面和弹窗，主界面不可删除。
- 复制弹窗并粘贴，底板由目标主界面重新生成。
- 粘贴到不兼容目标时显示提示。
- 查看右侧事件设置中的待绑定状态。

文案检查需要确认：

- 不再保留并列备选方案的表述。
- 不再使用横向工作台作为阶段一主交互。
- 不再把内部页面描述成正式课件流程步骤。
- 不再把事件关系做成右侧独立图谱。
- 不再出现旧版关系查看入口。

技术检查需要确认：

- HTML 原型脚本语法正常。
- 只改文档和原型文件。
- 不改真实编辑器代码。
- 不自动提交 Git。
