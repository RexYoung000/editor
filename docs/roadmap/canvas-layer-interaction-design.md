## 一、背景与结论

当前画布已经分别具备单选、多选数据、批量位移代码、框选、编组、对齐、缩放和平移等局部能力，但这些能力由 Laya 舞台命中、DOM 选框、React 状态和 Zustand 历史分别处理，用户的一次指针手势没有贯穿完整链路。

已确认的典型问题包括：

- 从已选元素 A 直接按下并拖动元素 B，第一次手势只会切换选中，第二次才能移动。
- 多选状态下，选框不接收鼠标事件；拖动任意已选元素会退化为单选，批量移动代码无法从真实画布操作触发。
- 单击已选元素但没有产生位移，也会写入一条空历史并清空重做链。
- 父容器和子元素可能同时进入选择集，修复多选后会产生子元素重复位移风险。
- 旋转元素仍使用未旋转矩形命中、框选和显示选框。
- 元素列表和画布层级方向相反：数据数组越靠后越在画布上层，但列表按原顺序向下展示，因此列表越靠下反而越靠前。
- 元素列表缺少折叠、图层组、搜索、锁定继承、主选中项和长列表拖动能力。

本轮不再按单个 Bug 修补，而是把画布选择、变换、镜头、图层树、属性面板和历史记录统一为一套桌面编辑器交互模型。

## 二、目标与非目标

### 2.1 目标

1. 用户在第一次按下元素时即可直接拖动，不需要先点一下再拖。
2. 单选、多选、编组和跨容器选择使用同一套命中与变换规则。
3. 多选支持整体移动、自由缩放、等比缩放和整体旋转。
4. 画布导航、吸附和智能参考线在不同缩放比例下保持稳定手感。
5. 元素列表升级为与画布同步的图层面板，列表越靠上代表视觉层级越高。
6. 区分运行容器与编辑器图层组，避免整理图层时意外改变课件运行结构。
7. 所有结构操作遵守“一次用户意图，一条历史记录”。
8. 普通关卡、内部页面和专注工作区复用同一套实现，不形成分支行为。

### 2.2 非目标

- 不加入倾斜、透视、自由变形或路径编辑。
- 多选缩放只改变元素位置和几何尺寸，不自动修改字号、描边、圆角、阴影或九宫格切片参数。
- 不改变课件运行时的页面尺寸，正式显示范围仍为 1920×1080。
- 不把图层组编译成运行组件，也不改变现有导出节点结构。
- 本文档不包含生产发布或安装包发布。

## 三、术语

| 术语 | 定义 |
|---|---|
| 页面画布 | 固定的 1920×1080 课件有效显示范围及其坐标系。 |
| 镜头 / 视口 | 用户观察画布的位置和缩放比例；移动镜头不改变画布及元素坐标。 |
| 图层 | 一个可编辑元素在图层面板中的表现。 |
| 运行容器 | 具有真实 `parentId` 的父元素，会改变子元素坐标系、裁切、运行和导出结构。 |
| 图层组 / 文件夹 | 纯编辑器组织节点，用于命名、折叠、选择和整体变换，不创建运行节点。 |
| 选择集 | 当前一个或多个被选中的图层。 |
| 主选中项 | 选择集中最后一次明确点击的图层，用于焦点展示和属性差异提示。 |
| 变换根 | 参与移动、缩放或旋转的最高层选中节点；其祖先已选中时，后代不再单独参与。 |

## 四、统一指针交互模型

画布交互统一为一个指针状态机，不再由 Laya 舞台和 DOM 选框分别决定同一次手势的含义。

建议状态如下：

```text
空闲
  ├─ 按下元素 → 待拖动
  ├─ 按下空白 → 待框选
  ├─ 空格/中键按下 → 镜头平移
  └─ 按下变换手柄 → 待缩放/待旋转

待拖动 / 待框选 / 待变换
  ├─ 屏幕移动不足 3px → 保持点击语义
  └─ 屏幕移动达到 3px → 进入移动/框选/缩放/旋转

活动操作
  ├─ 松开 → 一次性提交
  ├─ Esc → 恢复操作前快照
  └─ 窗口失焦/系统取消 → 恢复操作前快照
```

实现约束：

- 使用 Pointer Events 和 pointer capture 贯穿按下、移动、松开和取消。
- `pointerdown` 同时完成命中、选择更新和待拖动准备，因此首次手势可以直接移动新选中的元素。
- 每帧只更新 Laya 对象和选框预览，不逐帧写入 Store。
- `pointerup` 时统一写入 Store 并提交一次历史。
- 点击和变换共用一个旋转感知的命中服务，不再维护互相冲突的二次扫描规则。

## 五、选择规则

### 5.1 单选与多选

- 单击元素：使用该元素替换当前选择。
- macOS `Cmd + 点击`、Windows `Ctrl + 点击`：在选择集中增加或移除元素。
- 元素列表 `Shift + 点击`：选择可见列表中的连续范围。
- 点击画布空白：清空元素选择，但不切换当前内部页面。
- 拖动画布空白：开始框选。
- 多选中最后一次明确点击的元素成为主选中项。

### 5.2 框选

- 默认使用“相交选中”：选框与元素旋转后的真实几何区域相交即可选中。
- 不再使用 `Option/Alt` 切换框选模式，修饰键保留给拖动复制、临时独显等明确操作。
- 按住 `Cmd/Ctrl` 框选时，在当前选择上切换命中元素的选中状态。
- 锁定元素默认不进入框选，但仍可通过图层面板选中查看。
- 拥有子元素的运行容器不以大面积内部区域参与框选，框选直接命中其子内容；未选容器的内部空白可作为框选起点，容器本身通过画布线框、名称标识或图层面板选择。
- 框选结果必须经过父子规范化，不允许祖先和后代同时进入选择集。

### 5.3 父子层级

- 点击可见子元素时优先选中子元素。
- 容器内部区域始终不参与点击命中；点击时继续向下查找最上层普通组件，没有普通组件时才作为空白画布开始框选。
- 运行容器无论当前是否已有子元素，都在画布上显示低对比度常驻线框和名称，选中时增强；容器只通过线框、名称或图层面板选择和拖动，不依赖大面积隐形命中区域。
- 选中容器内组件时，组件保持蓝色主选中框，其直接父容器使用青色线框和增强名称表达层级上下文；上下文容器不进入选择集、不显示手柄，也不参与移动。
- 子组件允许超出父容器范围，父容器尺寸默认保持固定，不因子组件移动自动拉伸，也不强制把子组件限制在容器内部。
- 选中的子组件超出父容器时，直接父容器的上下文线框和名称改用琥珀色警示；警示只表达真实 `parentId` 层级中的越界，不改变选择集或变换行为。
- 属性面板在越界时提供“移回容器”和“扩展容器”两个主动操作：前者平移当前子组件到可完整容纳的位置，后者只扩大父容器以包含全部后代内容。
- 子组件自身的旋转包围范围大于父容器时不能完整移回，应先扩展容器；扩展左侧或上侧边界时必须保持容器及全部后代的画布绝对位置不跳动。
- 仅在几何位置上被容器覆盖、但没有真实 `parentId` 关系的组件，不触发容器上下文高亮；多选跨容器时分别高亮各元素的直接父容器。
- 选择父容器时自动排除其所有后代；选择子元素时自动移除已选祖先。
- 拖动父容器只修改父容器坐标，后代通过真实层级自然跟随。
- 不同运行容器中的元素可以一起选择和变换，计算统一使用画布绝对坐标，提交时再还原为各自父容器的局部坐标。

### 5.4 重叠、编组与锁定

- 重叠同级元素默认命中视觉最上层。
- 当前已选元素的可视区域优先保持可拖，不被另一个上层元素的二次命中抢走。
- 单击图层组成员时选中整组；双击进入组内选择。
- 锁定元素可以在画布或图层面板中选中查看，但不能移动、缩放、旋转或删除。
- 隐藏元素不参与画布命中、框选、吸附或智能参考线。

## 六、移动、复制、缩放与旋转

### 6.1 移动

- 未选元素可在第一次按下并拖动时直接选中和移动。
- 拖动任意已选元素会移动整个选择集，并保持元素相对位置。
- `Shift + 拖动`将移动限制到起始后的主方向（水平或垂直）。
- 网格关闭时拖动过程连续跟手，松开时再提交整数画布坐标。
- 锁定元素不进入变换根，也不会在拖动预览中短暂移动后回弹。
- 移动子组件越过父容器边缘时继续跟手，不做边界阻挡或自动扩容；父容器边缘吸附与参考线统一留在智能吸附批次实现。
- “移回容器”和“扩展容器”都作为显式、可撤销的原子操作提交，每次只生成一条历史。

### 6.2 拖动复制

- macOS 使用 `Option + 拖动`复制当前选择。
- Windows 使用 `Ctrl + 拖动`复制当前选择。
- 支持单个元素、多选元素和图层组。
- 复制时重新生成元素、动作和必要的分组 ID，保持复制内容内部关系。
- 复制和移动作为一个原子操作提交，只生成一条历史。

### 6.3 多选缩放

- 多选时显示统一包围框和八个缩放手柄。
- 默认允许水平、垂直自由缩放。
- 按住 `Shift`锁定原始选择集宽高比。
- 缩放按照包围框比例更新所有变换根的位置、宽度和高度。
- 只缩放几何数据，不自动修改字号、描边、圆角、阴影或九宫格参数。
- 图层组和跨容器选择遵守相同几何规则。

### 6.4 旋转

- 单选、多选和图层组包围框均提供旋转手柄。
- 多选以选择集中心为旋转中心，同步更新元素绝对位置与自身角度。
- 按住 `Shift`以 15° 为步长吸附。
- 接近 0°、90°、180°、270° 时自动吸附并显示角度。
- 点击命中、框选、包围框和缩放手柄全部使用旋转后的真实几何范围。
- 属性面板继续支持精确角度输入。

## 七、吸附、网格与参考线

- 拖动和缩放均支持元素边缘、中心线、画布边界、用户参考线和网格吸附。
- 元素接近其他元素的边缘或中心时显示智能参考线。
- 显示当前选择与参考元素之间的像素距离。
- 吸附容差按约 5px 屏幕距离计算，不随画布缩放比例改变手感。
- 网格显示与网格吸附拆分为两个独立设置。
- 为避免与 Windows 的 `Ctrl + 拖动复制`冲突，临时关闭吸附使用平台化按键：macOS 按住 `Cmd`，Windows 按住 `Alt`。
- 按住 `Option/Alt`并悬停其他元素时显示选择集与目标元素的距离。
- 隐藏元素不参与吸附；锁定但可见的元素仍可作为参考。

## 八、画布边界与镜头导航

### 8.1 边界

- 1920×1080 页面画布是最终课件有效显示范围，边界必须始终清晰。
- 元素允许移动到画布外，画布外区域作为临时摆放和入场动画工作区。
- 画布外元素保持可见、可选、可拖回；选框不能被页面边界裁掉。
- 预览和导出只显示有效画布范围，外部内容自然裁切。
- 元素完全位于画布外且没有相关动画或动作时显示非阻塞提醒。
- 提供“定位到选中元素”和“将选中元素移回画布”。

### 8.2 导航

- `空格 + 左键拖动`：平移镜头。
- `中键拖动`：平移镜头。
- 普通滚轮：纵向平移。
- `Shift + 滚轮`：横向平移。
- `Cmd/Ctrl + 滚轮`或触控板捏合：以鼠标位置为中心连续缩放。
- `Cmd/Ctrl + + / -`：分级放大、缩小。
- `Cmd/Ctrl + 0`：恢复 100%。
- `Cmd/Ctrl + 1`：适应完整画布。
- `Cmd/Ctrl + 2`：缩放到当前选择。
- `Cmd/Ctrl + 3`：保持缩放比例并居中当前选择。
- 缩放范围为 10%–400%；Mac 触控板输入使用阻尼和累计，避免每个滚轮事件直接跳级。
- 平移状态必须完全屏蔽元素选择、框选、变换和行内编辑。
- 镜头变化不进入课件历史，也不修改画布或元素坐标。

## 九、图层面板

### 9.1 布局

- “元素列表”统一更名为“图层”。
- 图层面板默认停靠在左栏下方并显示当前页面图层，也可以自由浮动，或磁吸到页面栏右侧、属性栏左侧形成独立列。
- 普通工作区和专注工作区复用同一个图层面板实例，不再把固定高度的元素树嵌在当前内部页面行下。
- 拖动标题栏时移动的是包含真实内容的完整面板；拖动中约 65% 透明，自由浮动时约 90% 透明并轻微模糊背景，停靠时不透明。
- 自由放置是主要能力，磁吸只是整理辅助。仅在靠近三个停靠边缘时显示细线或小标签提示，不使用覆盖大面积工作区的目标框。
- 浮动状态可以同时调整宽高；左右停靠只调整列宽；左下角停靠只调整高度。各模式都可以收起，并提供恢复默认布局入口。
- 面板位置和尺寸在窗口变化后自动约束到编辑器可用范围内，不能把标题栏、收起入口或尺寸手柄留在屏幕外。
- `Esc` 取消当前拖动并恢复拖动前布局；松手后的停靠或自由位置才写入本机偏好。
- 位置、尺寸、停靠方式和展开状态作为编辑器全局偏好保存，不进入课件数据，也不改变画布坐标、预览或导出结果。
- 普通工作区左栏默认约 280px，可在 240–420px 调整。
- 专注工作区默认 320px，继续在 280–440px 调整。

### 9.2 图层行

- 默认行高约 30px，层级缩进约 16px。
- 行内固定保留展开箭头、类型图标、图层名称、显隐和锁定状态。
- 组件类型、完整名称和父级路径通过悬停提示补充。
- 删除等低频操作仅在悬停或右键菜单中显示。
- 长名称省略显示，不挤压显隐和锁定列。
- 主选中项使用比普通多选项更明确的焦点边框。

### 9.3 层级方向

- 图层面板越靠上，画布视觉层级越高；越靠下，视觉层级越低。
- 同一运行父级内按“最上层到最下层”展示。
- 运行容器作为可展开节点，子图层在节点下方展示，并在各自父级内继续遵守上高下低。
- 实施时优先反转同级元素的展示和拖放索引，不重写历史 `elements[]` 数据，避免旧课件导出层级变化。

### 9.4 运行容器与图层组

- 运行容器是课件真实节点，拖入容器会改变 `parentId`、局部坐标、裁切和导出结构。
- 图层组是纯编辑器文件夹，只改变组织、折叠、选择和整体变换，不改变运行父级。
- 图层组允许中文命名、折叠和嵌套。
- 同一图层组的直接成员必须属于同一个运行父级。
- `Cmd/Ctrl + G`创建图层组；`Cmd/Ctrl + Shift + G`解散图层组并保留内容。
- 删除图层组时明确提供“删除组和内容”与“仅解散组”两种结果，不静默删除后代。
- 拖放预览必须区分“移入运行容器”和“移入图层文件夹”，并说明是否改变运行结构。

### 9.5 展开、搜索与筛选

- 容器和图层组均支持展开/收起、全部展开和全部收起。
- 每个课程和页面记住本机折叠状态；折叠属于编辑器视图偏好，不参与导出。
- 搜索匹配图层名称、组件标识、组件类型和完整父级路径。
- 搜索期间临时展开匹配项的祖先，清空搜索后恢复原折叠状态。
- 提供“全部、仅选中、隐藏、锁定、按组件类型”等轻量筛选。
- 画布选中图层时只同步高亮，不强制滚动列表；提供“在图层面板中定位”。

### 9.6 图层选择与拖放

- 单击替换选择，`Cmd/Ctrl + 点击`切换非连续选择，`Shift + 点击`选择连续范围。
- 拖动任意已选图层时，同一运行父级内的选择作为一个连续区块调整层级。
- 多选分属不同运行父级时禁止批量调整层级，并说明原因。
- 跨运行容器拖放必须校验组件能力，保持画布绝对位置，并作为一次历史提交。
- 无效投放必须显示原因，不再静默失败。
- 长列表拖放使用低速边缘自动滚动：约 48px 边缘区、停留 300ms 后不超过 2px/帧，无加速，离开立即停止并保留最后有效落点。
- `Cmd/Ctrl + ] / [`：上移或下移一层。
- `Cmd/Ctrl + Shift + ] / [`：置顶或置底。

### 9.7 显隐与锁定

- 图层行固定提供显隐和锁定列。
- 隐藏容器或图层组时隐藏全部后代，但保留每个子图层原来的独立显隐状态。
- 重新显示父级后，原本单独隐藏的子图层仍保持隐藏。
- 锁定容器或图层组时，全部后代不能通过画布移动、缩放、旋转、删除或框选。
- 子图层仍可在图层面板中选中查看，并显示“受父级隐藏/锁定”的继承状态和来源。
- `Option/Alt + 点击眼睛`临时独显当前图层或组，再次点击恢复此前状态。
- 显隐和锁定操作各自作为一条历史记录。

### 9.8 图层名称与组件标识

- 图层名称面向老师，允许中文、空格和重复，例如“鳄鱼按钮”“弹窗背景”。
- 组件标识面向运行和导出，继续使用英文、数字、下划线和连字符，并保持现有唯一性约束。
- 图层面板默认显示图层名称；未设置时依次回退显示组件标识和组件类型。
- 双击图层行只修改图层名称，不改变动作、变量和导出关系。
- 组件标识放入属性面板高级信息中，需要修改时继续校验。
- 复制元素时继续按现有规则生成新的唯一组件标识，并基于源图层显示名称生成当前页面内可区分的默认副本名称。
- 首次复制“确定按钮”得到“确定按钮 副本”，继续复制得到“确定按钮 副本 2”“确定按钮 副本 3”；复制已经带副本后缀的图层时仍回到原始名称寻找下一个可用序号，不产生“副本 副本”。
- 副本名称只负责复制完成后的默认区分；老师之后仍可把任意图层改成相同名称。

### 9.9 固定工具与后续右键菜单

- 对齐、分布等多选工具移出图层滚动内容底部，放入固定工具区或画布顶部工具栏。
- 阶段一不以完整右键菜单作为图层面板收口条件，先保证层级、选择和固定工具入口完整可用。
- 完整图层右键菜单进入长期需求池，作为独立 Issue 实施和验收。
- 图层右键菜单至少包含：重命名、复制、删除、编组/解组、显隐、锁定、上移、下移、置顶、置底、在画布中定位、移入容器。
- 多选时菜单动作作用于完整选择集，并遵守一次操作一条历史。

## 十、选择集属性

阶段一多选时，右侧属性栏显示基础“选择集属性”，不再伪装成某一个元素的属性：

- 显示已选数量和主选中项。
- X、Y、宽、高表示整个选择包围框。
- 修改 X、Y 会整体移动选择集。
- 修改宽、高会按比例更新所有元素的位置和几何尺寸。
- 提供宽高比锁定按钮；锁定后修改宽或高执行等比缩放。
- 显隐、锁定和透明度支持批量设置。
- 对齐和分布放在固定工具区，不随图层列表滚动。
- 数值提交与画布变换遵守相同事务和历史规则。

以下高级批量编辑能力进入长期需求池，以独立 Issue 实施：

- 同类型多选时显示共同且可安全批量修改的属性。
- 不同类型混选时只显示位置、尺寸、显隐、锁定、透明度、对齐和分布。
- 父容器仅在全部元素都可进入同一目标容器时开放批量修改。

## 十一、历史、取消与异常恢复

- 单击、切换选中、框选和镜头导航不写入课件历史。
- 一次移动、复制拖动、缩放或旋转，无论包含多少元素，只生成一条历史。
- 按住方向键连续移动，松开按键后合并为一条历史。
- 对齐、分布、编组、解组、多选删除、批量粘贴和跨容器移动各自只生成一条历史。
- 活动变换期间按 `Esc`恢复操作前快照，不写历史。
- 鼠标在编辑器窗口外松开时提交最后有效位置。
- 窗口失焦、应用切到后台或系统取消指针时恢复操作前快照。
- 操作失败时整体回退，不允许部分元素成功、部分元素失败。
- 没有实际数据变化时不写历史，也不清空重做链。

## 十二、数据与兼容设计

### 12.1 图层名称

- 图层名称建议保存为 `Element.props._editorLabel`。
- `_` 前缀字段继续遵守编辑器专用规则，导出前剥离。
- 历史课件没有该字段时直接使用现有 `Element.name`，不做强制迁移。

### 12.2 图层组

每个元素页面（普通主页面或 InternalPage）增加可选的编辑器图层组元数据：

```ts
interface EditorLayerGroup {
  id: string;
  name: string;
  runtimeParentId?: string;
  parentGroupId?: string;
}
```

- `Element.groupId`继续作为元素所属图层组 ID，避免破坏现有编组选择逻辑。
- `EditorLayerGroup`补充组名称、真实运行父级和嵌套文件夹关系。
- 图层组元数据不参与运行编译和资源扫描。
- 同组成员在同一运行父级的 z-order 中保持连续，组拖放以连续区块操作。
- 本机展开/收起状态使用课程 ID、页面 ID 和组 ID 保存为编辑器偏好，不写入课件数据。

### 12.3 旧编组兼容

- 旧课件只有 `groupId`、没有组元数据时，在编辑器中生成默认名称“图层组”。
- 旧组成员属于同一运行父级时直接展示为文件夹。
- 旧组跨越不同运行父级时，不自动改写父子关系或坐标；成员继续保持原有编组行为，并以“旧版跨容器编组”提醒展示，用户重新编组后再转为新模型。
- 新建图层组不允许跨运行父级。

### 12.4 层级顺序

- `elements[]`继续保持现有“同级数组索引越大，视觉层级越高”的存储与导出语义。
- 图层面板只把同级元素反向展示为“最上层在最上方”。
- 图层拖放先从当前视觉列表移除被拖图层，再把视觉插入位转换为同级存储插入位；视觉索引 `0` 对应存储末尾，视觉列表末尾对应存储索引 `0`。
- 同级拖动和跨容器拖动使用同一转换规则；跨容器仍沿用现有父级能力校验和坐标处理。
- 旧课件无需重排数组，画布节点顺序、动作引用和导出结果不因图层面板反向展示而改变。

## 十三、实施架构建议

建议拆出以下共享能力：

1. `CanvasInteractionController`：统一指针状态、修饰键、pointer capture、取消和提交。
2. `SelectionModel`：单选、多选、框选、父子规范化、主选中项和图层组解析。
3. `GeometryService`：绝对/局部坐标转换、旋转命中、包围框、批量移动/缩放/旋转。
4. `SnapEngine`：网格、画布、元素、中心和间距吸附，输出参考线与距离提示。
5. `TransformTransaction`：记录操作前快照、预览状态、一次提交、取消和历史合并。
6. `LayerTreeModel`：运行容器、图层组、反向层级展示、折叠、搜索、筛选和拖放映射。
7. `ElementTraversal`：继续复用内部页面已抽取的页面遍历能力，保证普通页和内部页使用同一数据入口。

不得继续保留“Laya 舞台负责首次选择、DOM Overlay 只负责后续拖动”的双轨方式。Laya 继续负责组件渲染，DOM 继续负责选框和参考线，但交互决策必须由同一个控制器完成。

- 吸附容差固定为约 `5px` 屏幕距离，并按当前缩放换算为画布距离。
- 同一次手势优先保持已经命中的参考目标，指针离开较宽的释放范围后再切换，避免相邻参考线之间抖动。
- 同一个吸附修正同时成立多个对齐关系时，参考线必须完整反馈，而不是每个方向只保留一条。两个同尺寸组件整体对齐时显示对应的两条外边线，中心线不重复叠加；不同尺寸只有中心对齐时仍显示中心线。
- 候选优先级只用于决定最终吸附位置，不能过滤该位置上同时成立的其他关系；同一坐标同时命中页面和具体组件时，视觉上优先显示组件之间的局部参考线，避免贯穿画布的页面线掩盖组件对齐。
- 参考线使用与蓝色选择框明确区分的高对比玫红色，并在关联对象范围两端各延伸约 `10px` 屏幕距离，避免边线与选择框、缩放控制点重合后不可见。
- macOS 按住 `Cmd`、Windows 按住 `Alt`时临时关闭智能吸附；现有 `Shift`轴锁定、等比缩放和拖动复制手势保持不变。
- 智能吸附命中时优先于现有网格取整；未命中时继续沿用当前网格行为，网格显示与吸附开关仍留给 #15 拆分。
- 参考线只在当前有效命中存在时显示，完成、取消、失焦或切换操作后立即清除。

本批自动测试至少覆盖页面与元素候选、隐藏与锁定规则、不同缩放阈值、目标保持与释放、旋转选择移动、父容器边缘以及旋转缩放手柄。

第三批实际实现保持现有变换事务和单条历史入口不变，新增纯计算吸附引擎，并由移动与缩放手势共同调用。候选在单次手势开始后复用，避免随每帧拖动重复扫描画布。视觉验收发现初版每个方向只显示一个主命中，无法表达同尺寸组件同时成立的上下边或左右边关系；实现已调整为按最终吸附修正收集全部同时成立的关系，并在同一目标的两条外边都成立时省略重复中心线。后续录屏复验又发现页面候选优先级会误过滤同位置的组件关系，现已把“位置选择”和“关系显示”拆开，并在页面线与组件线重合时保留更具体的组件局部线。自动检查扩展到对应单元测试，`pnpm lint`、`pnpm test` 与 `pnpm build` 均通过；Electron 开发进程可正常启动。当前运行环境无法读取 Electron 窗口，参考线视觉层级、吸附手感和修饰键实际体验保留为 PR 验收项，不记录为已人工通过。

### 第四批距离提示、等间距与辅助设置实施范围

本批由 [Issue #15](https://github.com/RexYoung000/editor/issues/15) 承载，在第三批智能吸附基础上补齐 Axure 式动态距离判断与三项及以上元素的等间距增强，并把画布定位辅助拆成五项独立偏好。

- 画布顶部固定提供“辅助工具”入口，集中管理“网格显示、网格吸附、智能吸附、参考线、距离提示”五项设置与“恢复默认”操作。
- 五项设置互不改写：网格显示只控制背景网格；网格吸附只控制 `20px` 网格取整；智能吸附只控制页面、元素和父容器的对齐吸附；参考线只控制智能吸附命中后的对齐线显示；距离提示独立控制两元素动态测距、三元素等距反馈与接近等距位置时的辅助吸附。
- 默认状态为网格显示关闭、网格吸附关闭、智能吸附开启、参考线开启、距离提示开启。
- 偏好保存在当前电脑的编辑器本地存储中，跨课程、普通页、内部页面和应用重启复用；不写入课程数据、撤销历史或导出结果。
- 移动单个元素或多选整体时，只在当前选择与参考元素形成明确同行或同列关系时显示动态距离：垂直投影至少重叠较短元素的 `25%` 才显示水平距离，水平投影满足同样条件才显示垂直距离。
- 斜对角关系不显示距离；普通测距只选择最近的一个有效相邻元素并显示一个方向，避免同时连接多个元素或形成横纵十字。
- 选中元素后按住 `Alt/Option` 悬停另一个元素，可以在不移动时使用相同规则查看两者距离；松开按键、移出目标或关闭距离提示后立即清除。
- 等间距计算抽离为不依赖 React 与 Laya 的纯逻辑，移动单个元素或多选整体时，以选择集的画布绝对包围框作为一个排列项。
- 水平与垂直等间距至少覆盖“移动项位于两个参考项之间”和“移动项位于两个连续参考项外侧”两类常见排列；隐藏元素不参与，锁定但可见元素继续作为参考。
- 等距吸附与智能吸附按当前手势中更小的屏幕距离修正竞争，同一方向不叠加两次修正；最终位置同时满足两类关系时，可以同时显示对应视觉反馈。
- 动态距离与等距辅助线使用高对比玫红色，线条随画布缩放而定位，文字与端点保持稳定屏幕尺寸。三元素等距成立时只显示两段相等距离，隐藏普通两元素测距，不叠加重复信息。
- macOS `Cmd`、Windows `Alt`仍只临时关闭智能吸附，不修改五项持久化设置；网格吸附与等距辅助是否启用继续由各自开关决定。
- 本批不实现从标尺拖出的永久参考线，不修改缩放、旋转、历史、课程数据和导出协议。

本批自动测试至少覆盖五项默认值、损坏偏好恢复、独立开关组合、保存与恢复默认，两元素同行/同列动态测距、斜对角过滤，以及水平/垂直的居中与外侧等距、不同缩放阈值、隐藏和锁定参考项。Electron 真实画布验收覆盖弹层位置、动态距离变化、`Alt/Option` 悬停测距、跨页面与重启保持、距离文字可读性，以及智能吸附和等距吸附同时开启时的手感。

第四批初版只在三元素等距命中时显示距离，真实体验过于离散。经 Axure 官方行为、录屏和对话内可拖拽 Demo 预验收，规则调整为“两元素同行/同列动态测距 + 三元素等距增强”：斜对角不测量，普通状态只显示最近相邻元素的单轴距离，等距成立时切换为两段成组反馈；`Alt/Option` 悬停使用相同测距规则。自动检查扩展到完整 69 项单元测试，覆盖五项偏好、旧偏好兼容、同行/同列测距、斜对角与擦边过滤、最近邻选择、水平/垂直等距、缩放阈值、目标保持和隐藏/锁定规则；`pnpm lint`、`pnpm test` 与 `pnpm build` 均通过。Electron 真实画布已由 Rex 验收动态距离、视觉密度与等距反馈，确认可以合入。

### 第五批图层名称与视觉顺序实施范围

本批由 [Issue #16](https://github.com/RexYoung000/editor/issues/16) 承载，只建立老师可读的图层名称并统一图层面板的视觉层级方向，不提前实现搜索、折叠、锁定继承、图层组或完整右键菜单。

- 图层名称写入 `Element.props._editorLabel`，允许中文、空格和重复；清空后删除该编辑器字段并回退显示组件标识或组件类型。
- 图层行双击和属性面板基础信息都只修改图层名称；组件标识移入属性面板“高级信息”，继续使用现有字符、首字符和唯一性校验。
- 图层名称变更不联动 `Element.name`、`props.var`、动作目标或导出节点，撤销和重做只恢复本次名称变化。
- 同一运行父级内反转展示顺序，图层面板越靠上代表画面层级越高；运行容器的子图层递归遵守相同方向。
- 拖动落点以视觉顺序计算并转换为既有存储顺序，`elements[]`、画布节点创建顺序和导出语义保持不变。
- 复制继续生成唯一组件标识，同时使用当前页面全部图层显示名称寻找“副本”“副本 2”等下一个可用默认名称；复制已带副本后缀的名称时先还原基础名称。
- 没有 `_editorLabel` 的历史课件直接使用组件标识或类型作为显示名称，不要求数据迁移。

本批自动测试至少覆盖旧数据回退、中文和重复名称、视觉/存储索引转换、同级与跨父级排序、副本名称递增、组件标识独立性，以及撤销和重做。Electron 真实画布验收覆盖列表上下顺序、遮挡层级、双击重命名、属性面板编辑、连续复制和重新打开课件。

第五批实际实现保持 `elements[]`、画布节点顺序和导出协议不变，新增独立图层展示模型统一旧数据回退、视觉顺序换算和副本命名；图层行与属性面板共同编辑 `_editorLabel`，组件标识收进“高级信息”，并补齐唯一性校验。`Cmd/Ctrl + ] / [`与带 `Shift`的置顶、置底快捷键使用同一视觉方向；同级和跨父级拖放均只提交一条历史。完整 80 项单元测试、`pnpm lint`、`pnpm build`和 `git diff --check`均通过，导出回归确认图层名称不会进入运行场景。Electron 已通过本地 Vite 服务启动并进入编辑器首页；图层遮挡顺序、重命名手感、连续复制和重新打开课件仍保留为 PR 真实画布验收项。

### 第六批图层显隐、锁定与继承实施范围

本批由 [Issue #18](https://github.com/RexYoung000/editor/issues/18) 承载，补齐图层面板的自身状态、父级继承状态和编辑限制，不建立第二套元素状态字段。

- 编辑器显隐继续写入 `Element.props._editorHidden`；编辑器锁定继续写入 `Element.locked`。两者的父级影响均由统一派生规则计算，不把继承结果写回子元素。
- 图层面板同时显示自身显隐/锁定状态与“受父级隐藏/锁定”的来源；父级恢复后，子图层原有自身状态保持不变。
- 隐藏元素及其后代不参与画布命中、框选、变换、智能吸附、参考线和距离提示；锁定但可见的元素仍可从画布或图层面板选中查看。
- 锁定元素及受父级锁定的后代不显示可用变换手柄，不参与移动、缩放、旋转、删除、排序、改父级和编组；混合选择中的未锁定元素仍可变换。
- 属性面板保留锁定对象的只读信息，并明确显示自身锁定或父级锁定的来源；会改变内容、几何或结构的控件不可用，属性区域整体置灰并显示不可操作状态。
- 单个和选择集的显隐/锁定操作各写入一条历史；编辑器显隐不改变预览、发布和课件运行时的 `visible` 语义。
- 本批不实现独显快捷操作、图层组数据模型、完整右键菜单或高级批量属性编辑；这些能力按后续 Issue 处理。

本批自动测试覆盖自身与父级多层继承、解除父级后恢复子级状态、画布命中/框选/吸附排除、锁定选择与变换限制、批量操作单条历史和旧数据默认值。Electron 验收覆盖图层行状态反馈、锁定对象查看与限制、父级状态切换、普通页与内部页面一致性。
