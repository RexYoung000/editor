## 阻塞性问题（阻止工作流程）

| # | 问题 | 影响 | 文件 |
|---|------|------|------|
| B1 | 课件 ID 不支持中文 | 教研习惯用中文命名 | CreateCourseDialog.tsx |
| B2 | DragObj 的正确目标需手动输入名称 | 容易输错，无校验 | PropertyPanel.tsx |
| B3 | changePage 用页面索引而非 ID | 页面重排后跳转错误 | export.ts |
| B4 | 图片上传 courseId 硬编码为 'default' | 所有课件图片混在一起 | FieldRenderer.tsx |
| B5 | 无重复课件 ID 检测 | 新课件覆盖旧课件 | editorStore.ts |

## 困惑性问题（用户不理解）

| # | 问题 | 影响 |
|---|------|------|
| C1 | 无欢迎页或教程 | 新用户不知道怎么开始 |
| C2 | 页面重命名需双击 | 不明显，容易忽略 |
| C3 | 设置父容器后元素位置变化 | 坐标变为相对父容器，用户困惑 |
| C4 | 预览模式全屏黑色 | 看起来像崩溃 |
| C5 | "皮肤"概念不直观 | 教研不理解什么是皮肤 |
| C6 | 元素名称自动生成（Label_1） | 多个同类型元素无法区分 |
| C7 | Action 目标选择只显示名称 | 无法区分同名元素 |
| C8 | 发布后无课件 ID 显示 | 无法分享给学生 |

## 缺失功能

| # | 问题 | 影响 |
|---|------|------|
| M1 | 音频路径无文件选择器 | 必须手动输入路径 |
| M2 | 无元素命名规范提示 | 元素难以区分 |
| M3 | 无 Action 预览 | 必须发布才能测试交互 |
| M4 | 无保存状态指示器 | 不知道是否已保存 |
| M5 | 无拖拽对齐参考线 | 精确定位困难 |
| M6 | 页面删除无确认 | 容易误删 |
| M7 | 页面缩略图模糊 | 无法区分页面内容 |

## 数据丢失风险

| # | 问题 | 影响 |
|---|------|------|
| D1 | 自动保存间隔 30 秒 | 关闭浏览器可能丢失最近修改 |
| D2 | 上传图片存在 public/uploads | 服务器重启后可能丢失 |
| D3 | 撤销历史限 50 步 | 大量操作后无法回退 |
| D4 | 页面复制名称累加 "(Copy)" | 多次复制名称混乱 |

## 按优先级排序的修复建议

### P0：必须修复（阻塞工作流）
1. changePage 改用页面 ID 而非索引
2. DragObj 正确目标改为下拉选择
3. 图片上传用实际 courseId
4. 重复课件 ID 检测
5. 页面删除加确认弹窗

### P1：应该修复（严重影响体验）
6. 音频路径加文件选择器（复用 file 类型字段）
7. 保存状态指示器（"已保存" / "未保存"）
8. 自动保存改为每次修改后保存（防抖 2 秒）
9. Action 目标显示名称 + 类型 + 位置
10. 预览模式加过渡动画（不要突然黑屏）
11. 发布后显示课件 ID + 复制按钮

### P2：建议修复（改善体验）
12. 欢迎页 / 快速入门提示
13. "皮肤"改为"外观样式"
14. 元素名称可在画布上双击编辑
15. 页面缩略图提高质量
16. 页面复制名称改为"页面名 2"而非"页面名 (Copy)"
17. 父子关系设置时提示坐标将变为相对坐标
