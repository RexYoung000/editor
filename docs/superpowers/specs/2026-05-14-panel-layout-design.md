# 左侧面板重构：属性面板与元素列表同时可见

## 背景

当前编辑器右侧 PropertyPanel (256px, w-64) 用 tab 切换"属性"和"元素列表"两个视图。选中元素时自动跳到属性 tab，取消选中时回到元素列表 tab，用户需要频繁切换，无法同时看到两者。

## 设计方案

**方案B：元素列表移到左侧，属性面板独占右侧。**

### 布局结构

```
┌─────────────┬──────────────────┬─────────────┐
│  左侧 240px │    画布 (flex-1) │ 右侧 256px  │
│             │                  │             │
│ ┌─────────┐ │                  │ ┌─────────┐ │
│ │页面列表 │ │                  │ │属性面板 │ │
│ │  ~45%   │ │                  │ │         │ │
│ ├─────────┤ │                  │ │         │ │
│ │元素列表 │ │                  │ │         │ │
│ │  ~55%   │ │                  │ │         │ │
│ └─────────┘ │                  │ └─────────┘ │
└─────────────┴──────────────────┴─────────────┘
```

### 具体变化

1. **左侧面板**
   - 宽度从 `w-52` (208px) 改为 `w-60` (240px)
   - 上下分割：页面列表占约 45%，元素列表占约 55%
   - 两个区域各自可滚动，中间有分隔线
   - 页面列表保持现有功能不变（预习/正课关卡、折叠展开）
   - 元素列表从右侧 PropertyPanel 中独立出来，成为左侧的一个新区域

2. **右侧面板 (PropertyPanel)**
   - 宽度保持 `w-64` (256px) 不变
   - 去掉 tab 切换机制（删除 `useState<'elements' | 'props'>('elements')`）
   - 去掉顶部 tab 按钮 UI
   - 去掉 `hasSelection` 时的自动切换逻辑
   - 始终只显示选中元素的属性内容
   - 无选中元素时，显示空状态提示（"请选择一个元素"）

3. **画布区域**
   - flex-1 自适应，宽度减少 32px（左侧从 208→240），影响很小

### 交互逻辑

- 选中元素 → 左侧元素列表高亮对应条目 + 右侧属性面板直接显示该元素属性
- 取消选中 → 左侧元素列表取消高亮 + 右侧属性面板显示空状态
- 切换页面 → 左侧页面列表更新 + 元素列表更新为新页面的元素
- 元素列表中的操作（拖拽排序、可见/锁定、删除）保持现有功能，只是位置从右侧移到左侧

### 涉及文件

| 文件 | 变化 |
|------|------|
| `src/App.tsx` | 修改布局结构：左侧加宽 w-60，新增 ElementList 区域；右侧 PropertyPanel 不变 |
| `src/components/PropertyPanel.tsx` | 删除 tab 切换逻辑和 tab UI，只保留属性内容渲染 |
| `src/components/PageList.tsx` | 宽度从 w-52 改为 w-60（或由父容器控制宽度） |
| 新建 `src/components/ElementList.tsx` | 从 PropertyPanel 中提取元素列表部分，作为独立组件 |
| `src/components/Canvas.tsx` | 无变化 |

### 不变的部分

- 页面列表的折叠/展开逻辑
- 元素列表的拖拽排序、可见/锁定、删除功能
- 属性面板的属性编辑功能
- 画布交互
- store 状态结构
