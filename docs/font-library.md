# 字体库与历史兼容

forge 的文本字体由 `src/elements/fontLibrary.ts` 统一注册。字体选择、编辑器画布、文字测量、文字图片烘焙、预览和正式导出都必须读取同一份配置，不在业务代码中硬编码字体路径或字体名。

## 预设字体

字体下拉使用单层列表，不再按“派培优 / 豌豆口才 / 豌豆益智”分类。内置字体保存在 `public/builtin/runtime/fonts/`，当前包含：

| 系列 | 用户可见名称 |
| --- | --- |
| 思源黑体 | ExtraLight、Light、Normal、Regular、Medium、Bold、Heavy |
| Arial | Regular、Bold、Italic、Bold Italic、Black |
| 黑体 | 黑体 |
| 罗马体 | 罗马粗、罗马粗斜、罗马细、罗马细斜 |

“思源黑体 Regular”是新建文本、内部字体生成和所有缺省场景的统一默认字体。新增字体时必须同时提供稳定的字体 ID、用户可见名称、内置资源路径和唯一的 `FontFace` 名称，并补充字体注册与资源完整性测试。

本地上传字体继续优先于预设字体。清除本地字体后，文本恢复使用元素保存的预设字体；元素没有有效预设字体时使用“思源黑体 Regular”。

## 历史课件迁移

已移除的方正字体不再保留文件、下拉选项或运行时配置。打开历史课件时，所有已删除或无法识别的 `fontLibraryId` 都迁移为“思源黑体 Regular”：

- 迁移在课件进入编辑器状态时完成，画布、预览和导出立即使用新默认字体。
- 迁移后的字体 ID 进入当前课件数据，下一次自动保存或手动保存时写回课件文件。
- 字体加载入口仍执行同样的缺省归一化，避免绕过编辑器加载流程的预览或导出使用设备字体。
- 旧字体与思源黑体的字宽不同，历史课件可能发生换行或高度变化；字体升级验收必须抽查包含标题、长段正文、粗斜体和固定宽高文本的历史课件。

## 编辑与导出边界

内置字体只用于编辑器渲染、测量和生成文字图片。`NewTextArea` 在预览和正式导出前烘焙为 PNG，课件运行时不动态加载 OTF/TTF，也不依赖播放电脑安装字体。

字体资源改动至少验证：

1. 字体下拉的名称、顺序和实际字形一致，没有旧业务分类。
2. 新建文本、历史课件和本地字体清除后的默认字体都是“思源黑体 Regular”。
3. 编辑、保存重开、预览和正式导出的换行、尺寸和字形一致。
4. 被删除字体不再出现在 `public/builtin/runtime/fonts/`、字体配置或导出产物中。
5. `pnpm lint`、`pnpm test`、`pnpm build` 通过，并完成 Electron 真实界面验收。
