## 用户可感知变化

### 课件与内部页面

- 支持普通页面和内部页面专注工作区，管理主界面、内容页与弹窗。
- 支持页面关系、弹窗遮罩、断链校验和内部页面真实预览发布。
- 支持正课、预习、作业、专题测评和复习课工程。

### 画布与图层

- 支持移动、缩放、旋转、框选、多选和拖动复制。
- 支持智能吸附、参考线、动态距离、等间距提示和画布辅助设置。
- 支持老师可读图层名称、显隐锁定、父级状态继承和编辑器图层组。
- 图层面板支持自由浮动、边缘停靠、尺寸调整和长列表滚动。

### 组件、动作与资源

- 支持 sdk_baiya 组件属性编辑、父子结构和资源路径处理。
- 支持任意可点击元素触发 SDK 题型判定，并分离触发元素、判定目标和结果动作。
- 支持资源库浏览、搜索、下载、Spine 导入和快捷预设。
- 支持课程本地保存、资源去重、工程编译、预览和发布。

## 交付组合

### 源代码

- Git Tag：`v1.1.0`。
- Tag 必须指向发布 PR 合并后的 `main` 提交。
- GitHub Release 自动提供源码 ZIP 和 TAR.GZ，不重复上传源码。
- 依赖只使用 `pnpm-lock.yaml` 锁定；发布候选已移除版本停留在 `0.0.0` 的旧 `package-lock.json`。

### Windows 安装包

- 目标文件名：`豌豆课件编辑器 Setup 1.1.0.exe`。
- 生成环境：Windows、Node.js 22 LTS、pnpm 10。
- 生成命令：`pnpm electron:build`。
- 安装包 SHA-256：待 Windows 最终产物生成后填写。
- Release Asset：待 Windows 真实安装验收后上传。

### 美术资源

- 正式来源：以公司 Windows 台式机在首版部署前最终整理完成的 `public/builtin/library/` 为准，不以开发 Mac 的本地素材目录作为发布依据。
- 快照标识：待 Windows 素材整理完成后生成，建议使用 `library-YYYYMMDD-r1`；同日修订递增末尾序号。
- 文件数量与聚合 SHA-256：待 Windows 正式目录完成后统计并填写，不包含 `.cache/`。
- 分发方式：素材快照单独备份和同步到公司台式机，不提交 Git，不上传 GitHub Release，也不进入老师端安装包。
- 变更规则：正式快照确认后不得原地覆盖同名快照；后续新增或替换素材时创建新的快照标识。

### 回退

本版本没有上一正式 Release。首次部署前必须记录并备份公司台式机当前代码提交、素材目录、`public/uploads/`、`preview-server/lessons/` 和服务配置。出现阻塞问题时先停止新服务并恢复该部署前备份，不使用 `main` 或任意提交替代正式回退点。

## 已知限制

- 当前内部服务依赖 `pnpm dev`，尚无 Windows 服务、进程守护和自动重启；终端或进程退出会中断使用。
- 服务仅适用于受控公司网络，不能直接暴露到公网。
- 图层搜索与折叠 [#17](https://github.com/RexYoung000/editor/issues/17)、基础选择集属性 [#20](https://github.com/RexYoung000/editor/issues/20) 尚未交付。
- 阶段一最终端到端回归 [#13](https://github.com/RexYoung000/editor/issues/13) 依赖 #17 和 #20，本版本不宣称阶段一全部结束。
- macOS 冒烟中存在编辑器模式主动抑制的 GameLoader `初始化Native异常` 控制台日志，界面未中断；Windows 真实验收需要继续观察。
- 当前 CI 只覆盖 lint、单元测试和静态构建，不覆盖 Windows 打包、真实 Electron、本地文件或公司局域网。

## GitHub Release 发布说明

### forge v1.1.0

这是 forge 的首个正式内部版本，建立公司台式机服务、老师端 Windows 客户端和美术资源之间的统一版本基线。

主要能力包括内部页面专注工作区、画布智能吸附与距离提示、可浮动图层面板、图层显隐锁定和编辑器图层组、资源库、五类课件工程以及 SDK 题型判定。

安装前请确认公司台式机已经部署 `v1.1.0` 对应代码和 Release 指定素材快照。老师首次使用必须安装本 Release 提供的 `豌豆课件编辑器 Setup 1.1.0.exe`，并填写公司台式机服务器地址。

已知限制和完整部署步骤见 [正式发板与内部部署](../internal-deployment.md)。
