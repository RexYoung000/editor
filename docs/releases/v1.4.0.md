## 用户可感知变化

### 普通事件在各类课件中正常执行

- 正课、预习、作业和专题测评统一执行点击、点击音效、加载和变化等普通事件。
- 同一元素的同一事件只绑定一次，多个动作继续按编辑顺序执行。
- 点击音效每次触发只播放一次；复习课继续保持纯视频结构。

### 预习与正课统一关卡结构

- 普通课件的预习与正课都支持一个大关卡包含一个或多个小关卡。
- 预习与正课都支持复制小关卡和完整复制大关卡；副本紧跟来源，并重建内部页面、元素、动作、分组及引用 ID。
- 预习预览和导出会为每个小关卡生成独立场景，并按顺序写入同一大关卡的 `subviews`，不再只生成第一页。
- 视频大关卡仍保持单页结构，不能新增小关卡，但可以整体复制。

### 画笔预览与编辑画布保持一致

- 画笔导出使用当前 SDK 可以创建的运行节点，同时保持已有课件数据兼容。
- 预览初始只显示画笔开关；点击后画板与清空按钮正常出现。
- 修复旧画笔内置资源路径重复拼接导致的按钮资源加载失败。

## 兼容性与交付决定

- 本版包含向后兼容的新能力，按 SemVer 从 v1.3.1 升级到 v1.4.0。
- 旧普通预习课件加载后自动开放多小关卡；旧视频关卡、作业、专题测评和复习课结构不变。
- 编辑器课件数据继续保存 `NewBrushSprite`，只在导出运行节点时转换为 SDK 已注册的 `BrushSprite`，不迁移已有课件。
- v1.3.1 之后没有修改 Electron 主进程、preload、IPC、本地编译依赖、打包配置或 `extraResources`。
- 因此老师端无需重新安装：公司服务器部署 `v1.4.0` 后，关闭并重新启动现有 v1.3.0 客户端即可加载新页面。
- 本版不生成新的 Windows 安装包；外置素材库继续沿用既有快照。

## 已知限制与未包含内容

- 画笔连续绘制手感与清空效果建议在正式环境做一次最终人工抽查。
- 本次不生成或上传新的 Windows 安装包，安装验证状态沿用 v1.3.0 Release。
- 本次不执行公司台式机正式部署、服务重启或老师端分发。
- 内部服务仍需运行 `pnpm dev`，不能使用静态 `pnpm build` 或 `pnpm preview` 代替。
- 不扩展作业、专题测评的多小关卡能力，不改变复习课纯视频结构。

## 部署与回退

- 公司服务器必须部署 `v1.4.0` Release 对应 Tag，不能直接跟随 `main`。
- 部署前保留 `public/builtin/library/`、`public/uploads/`、`preview-server/lessons/` 和本机配置，不使用 `git clean` 清理部署目录。
- 出现普通事件不执行、关卡结构丢失、预览无法启动或画笔运行异常时，服务器回退 `v1.3.1`；客户端继续使用 v1.3.0 安装包。
