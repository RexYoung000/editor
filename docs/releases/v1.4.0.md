## 版本范围

原 `v1.4.0` Tag 在 #128、#130 合入后提前创建，但当时没有部署、没有 GitHub Release，也没有对老师分发。随后两天又完成 8 个产品 Issue。经 Rex 确认，本次在正式发布前撤回旧 Tag，以发布修正 PR 的合并提交重新创建同名 Tag；最终 v1.4.0 共纳入 10 个产品 Issue。

## 用户可感知变化

### 课件事件、关卡和画笔

- 正课、预习、作业和专题测评统一执行点击、点击音效、加载和变化等普通事件；同一事件只绑定一次，多个动作继续按编辑顺序执行。
- 普通课件的预习与正课统一为“大关卡包含一个或多个小关卡”，都支持复制小关卡和完整复制大关卡。
- 预习预览和导出为每个小关卡生成独立场景并完整写入 `subviews`，不再只生成第一页。
- 视频大关卡仍保持单页结构，不能新增小关卡，但可以整体复制。
- 画笔导出改用当前 SDK 可创建的运行节点，并修复旧内置资源路径重复拼接导致的预览资源加载失败。

### 字体、图片和动作目标

- 字体下拉取消业务分类，改为 17 项单层列表；新增思源黑体、Arial 和黑体，保留四款罗马体。
- 新建文本统一默认使用思源黑体 Regular；历史方正字体、缺失字体和旧罗马体 ID 按兼容规则自动迁移。
- 普通图片支持左右和上下镜像，可组合、撤销、保存，并在编辑画布、预览和导出中保持一致。
- 图层重命名后，普通事件、SDK 判定、结果动作、画笔和入站引用等目标立即显示最新图层名称，同时继续使用稳定元素 ID 维持关系。

### 数学键盘、自定义答案和输入框

- 新增“小数与分数组合”“数学表达式”及四种数字百分比键盘，共六种数学键盘预设。
- 现有数字、分数和新增数学键盘统一支持黄、蓝、绿三色皮肤；百分号作为可见字符输入，不自动换算。
- 自定义答案键盘取消最多 9 项限制，支持更大数量的保存、生成、文字资源和导出；自动排版优先排满答案，清空键可以铺满独占末行。
- 普通输入框与分数输入框可独立选择黄、蓝、绿文字主题，新建默认蓝色，不与键盘皮肤互相覆盖。
- 输入框增加真实九宫格预览，可调整主字号和字符间距；分数输入框还可调整分数字号比例，并按实际位数动态布局。

### 预设模板

- 预设模板按“单页面关卡、内部关卡、视频关卡”分组，保留预设、自定义和可复制模板的一级导航。
- 新增木纹卷轴单页面与内部关卡模板；标题和正文可编辑，背景与标题框锁定，声音按钮可配置音频。
- 视频关卡在模板弹窗中整合预设、本地上传和资源库三种来源；已有大关卡新增小关卡时不再显示视频结构。

### 安全另存为课件

- “另存为课件”按规范化后的完整目标路径判断冲突，允许同一课件 ID 保存到不同目录。
- 当前路径直接阻止；有效同名课件需要二次确认替换；普通非空目录拒绝覆盖。
- 另存采用临时副本、备份、事务标记、完整性校验和中断恢复，不再把源文件合并写入目标目录。
- 成功后活动路径、远程本地资源映射和资源缓存同步切换；顶部显示当前课件目录入口。
- 阻止源目标嵌套路径和越出目标父目录的符号链接，替换时保留目标目录自己的 `.svn` / `.git` 信息。

## 兼容性与交付决定

- 本版包含向后兼容的新能力，版本号继续使用 `v1.4.0`；旧 Tag 未进入 Release 或部署，因此在正式发布前按授权修正代码基线。
- #145 修改 `electron/main.cjs`、`electron/preload.cjs` 并新增 `electron/courseSaveAs.cjs`，旧客户端没有对应 IPC，老师端必须安装 v1.4.0 Windows 客户端。
- 公司服务器与 Windows 安装包必须使用同一个最终 `v1.4.0` Tag，不能继续使用旧 Tag 或只更新其中一端。
- 旧普通预习课件加载后自动开放多小关卡；旧视频关卡、作业、专题测评和复习课结构不变。
- 历史输入框缺少新主题字段时继续使用原字体图行为；历史课件不会被强制改为新三色输入框主题。
- 历史方正字体会迁移到思源黑体 Regular，字宽变化可能影响固定宽度标题、长正文和文本高度，需要在真实旧课件中抽查。
- 内置字体、数学键盘、木纹卷轴模板、`game.zip` 和三类课件模板 ZIP 随源码 Tag 更新；外置 `public/builtin/library/` 快照不变。

## 已知限制与发布门槛

- Windows NSIS 首次安装、从 v1.3.0 覆盖安装、服务器地址保留、编译发布 IPC和重启仍需真机验收。
- #145 的 Windows 大小写路径已有自动测试；Windows 跨盘、真实文件占用、Defender 和普通权限目录仍需真机复验。
- 在 Windows 安装包完成上述验收前，GitHub Release 保持草稿，不对老师分发。
- 自定义答案数量不再设上限，但不提供分页、滚动键盘或自动缩小键帽；答案过多超出画布时由老师调整数量。
- 数学键盘只负责输入字符，不进行表达式求值、百分数换算、约分、通分或数学等价判断。
- 画笔连续绘制手感与清空效果建议在正式环境再做一次人工抽查。
- 内部服务仍需运行 `pnpm dev`，不能使用静态 `pnpm build` 或 `pnpm preview` 代替。
- 本次不执行公司服务器部署、服务重启、生产数据迁移或老师端分发。

## 部署与回退

- 公司服务器必须部署最终 `v1.4.0` Release 对应 Tag，并与同版本 Windows 安装包配套使用。
- 部署前保留 `public/builtin/library/`、`public/uploads/`、`preview-server/lessons/`、课程目录和本机配置，不使用 `git clean` 清理部署目录。
- 出现客户端 IPC 不兼容、另存失败、关卡结构丢失、预览无法启动或内置资源异常时，服务器回退 `v1.3.1`，客户端回退 v1.3.0 安装包。
