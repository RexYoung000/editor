## 用户可感知变化

- 文本工具在当前可见画布中央创建，新建后直接进入行内编辑。
- 文本支持自动宽高、固定宽度自动高度和固定宽高三种尺寸模式，并改善光标、选区、中文输入法和画布撤销体验。
- 编辑、画布显示、预览和导出 PNG 共享文字测量与换行规则，降低预览或发布后的换行和裁切偏差。

## 修复

- 修复插入分数后点击分数输入框导致预览卡死。
- 分子或分母获得焦点时禁用分数按钮，防止嵌套分数结构。
- 修复带内容分数整块删除后留下残缺编码和渲染残影。
- 补齐带整数部分的分数令牌解析，并增加重绘防重入保护。

## 明确不纳入本版

- 资源库独立搜索与三级快捷筛选 #73 尚未进入 `main`，v1.2.1 不宣称交付该能力。
- 不新增资源库正式素材和标签映射。
- 不修改 Electron 主进程、preload、本地 IPC、客户端依赖或打包配置。

## 已知限制与部署

- 当前内部服务仍依赖 `pnpm dev`，没有 Windows 服务守护和自动重启。
- 公司台式机必须部署本版本对应的 `v1.2.1` Tag，并沿用 v1.2.0 使用的素材快照。
- 现有老师端无需重装，服务器升级后关闭并重新启动客户端即可加载本版能力。
- v1.2.1 不生成或上传 Windows 安装包；新电脑需要安装客户端时，继续使用已验证的 v1.2.0 安装包。
- 部署前必须确认 `v1.2.0` 安装包、素材快照和运行数据备份仍可回退。
