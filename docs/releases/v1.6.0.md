## 版本范围

本版包含 v1.5.2 之后已经合入的一组向后兼容新能力和编辑体验修复，因此按 SemVer 升级 MINOR 至 v1.6.0。

- 新增“输入后立即 SDK 判断”，输入框在 `INPUT_LATER` 后即时执行正确、错误和未填写三态分支。
- 新增“播放正确音效 + 锁定判断输入框”动作，仅允许在 SDK 判定正确分支使用，并会锁定对应输入框、关闭同 camp 键盘。
- 优化输入框运行态反馈：错误时显示红色光晕，重新点击清除错误态；选中态资源替换为语义化黄色图片。
- NewTextArea 支持局部粗体、斜体和下划线，并修复富文本编辑时属性面板、画布点击和长文本回格造成的草稿或光标问题。

## 用户可感知变化

- 老师可以配置输入后立即给出 SDK 判断反馈，不必再依赖额外确定按钮。
- 答案正确时可以播放正确音效并锁定当前判定输入框，避免学生继续修改已经判定正确的答案。
- 输入错误反馈更明确，错误光晕和清除时机在编辑器预览与导出课件中保持一致。
- 文本组件可以混排局部粗体、斜体和下划线，文本编辑后点击画布或属性面板不会丢失未提交内容。

## 已知限制与未包含内容

- 本次不修改 Electron 本地文件、发布 IPC、SVN 流程或打包配置，因此不要求老师端强制覆盖安装。
- 本次不新增外置素材库内容；`public/builtin/library/` 继续沿用上一正式快照。
- 本次不执行公司服务器部署、服务重启、GitHub Release 创建、安装包上传或老师端正式分发。

## 部署与回退

- 公司服务器部署 `v1.6.0` Tag 后，老师端关闭并重新打开现有客户端即可加载新页面和内置运行资源。
- 如需给新电脑提供完整安装包，可按需从同一 Tag 执行 `pnpm electron:build`，并在 GitHub Release 中补充安装包和 SHA-256。
- 更新服务器前保留 `public/builtin/library/`、`public/uploads/`、`preview-server/lessons/` 和本机配置，禁止使用 `git clean` 处理部署目录。
- 若出现输入判断、文本渲染或导出运行异常，服务器回退 `v1.5.2`；回退后本版新增能力不可用。
