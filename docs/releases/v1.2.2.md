## 用户可感知变化

- 新增“青色题目版式”，线上作业与专题测评都可在新增关卡时直接套用。
- 新增“蓝色题目版式”，线上作业可在新增关卡时直接套用。
- 每套版式使用稳定的模板 ID；每次套用都会生成独立页面与元素，不会修改只读母版或其他已创建关卡。
- 模板背景和装饰默认锁定，题号、标题和正文可直接编辑。
- 正常课、预习和复习课的既有新增关卡流程保持不变。

## 项目治理

- 校准 #26、#27、#92 的看板状态，使 Issue、PR 与执行状态保持一致。
- 更新当前版本、阶段三进度和后续路线，并清理两条已合并的遗留远端分支。

## 明确不纳入本版

- 不增加新的模板 ID；后续版式需要独立演进时另立任务。
- 不预装选择、填空、拖拽等答题组件，不配置判定事件、答案或结果分支。
- 不新增资源库正式素材和标签映射。
- 不修改 Electron 主进程、preload、本地 IPC、客户端依赖或打包配置。

### 真实体验验收

- #102 / PR #103 已在 Electron 中完成线上作业与专题测评的模板筛选、直接套用、编辑、连续创建、保存重开、预览和本地真实导出验收。
- 线上作业可见两套模板；专题测评只显示青色题目版式。
- 青色模板生成 4 个图层，蓝色模板生成 5 个图层；背景和标题纸默认锁定，三个文字图层可编辑。
- 保存重开后关卡与布局保持；预览和本地导出的 scene、config 与三张运行时资源完整。
- 验收目录不是 SVN 工作副本，因此未执行 SVN 提交或正式课件发布。

## 已知限制与部署

- 当前内部服务仍依赖 `pnpm dev`，没有 Windows 服务守护和自动重启。
- 公司台式机必须部署本版本对应的 `v1.2.2` Tag；源码内置模板资源会随代码更新，不需要单独同步资源库素材。
- 现有老师端无需重装，服务器升级后关闭并重新启动客户端即可加载本版能力。
- v1.2.2 不生成或上传 Windows 安装包；新电脑需要安装客户端时，继续使用已验证的 v1.2.0 安装包。
- 部署前必须确认 `v1.2.1` 代码、v1.2.0 安装包、素材快照和运行数据备份仍可回退。
