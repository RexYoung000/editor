## 用户可感知变化

- 修复预习关卡预览中自定义答案输入框不可见、因而无法正常唤起自定义键盘的问题。
- 点击输入框后，自定义文本答案键盘可正常显示；点击答案键后，文字可回填到输入框。

## 影响范围与兼容性

- 预习预览配置现在与正式导出保持相同的固定子节点资源扫描边界，同时加载输入框底图和键盘预设图集。
- 正课、作业、专题测评继续加载输入框与自定义键盘所需图集；复习课保持纯视频配置，不生成题目场景。
- 不改变课程数据、导出目录、课件运行时协议或已有素材路径。

## 客户端与交付决定

- 本次修改位于公司台式机通过 Vite 服务下发的编辑器与预习导出逻辑。
- 未修改 Electron 主进程、preload、IPC、本地编译依赖、打包配置或 `extraResources`，也未依赖 v1.3.0 客户端不存在的新本地能力。
- 因此老师端无需重新安装：公司服务器部署 `v1.3.1` 后，关闭并重新启动现有 v1.3.0 客户端即可加载新页面。
- 本 Release 不生成、不上传新的 Windows 安装包，也不产生新的安装包 SHA-256。新电脑仍使用 v1.3.0 Release 中的 `Setup.1.3.0.exe`。

## 验证记录

- `pnpm install --frozen-lockfile`：通过；锁文件一致，仅出现既有的 `url.parse()` 弃用提醒。
- `pnpm lint`：通过，零错误。
- `pnpm test`：通过，231 / 231。
- `pnpm build`：通过，仅出现既有的大包体积与无效动态导入提醒。
- `pnpm audit --prod`：通过，无已知生产依赖漏洞。
- GitHub Actions Node.js 22 自动测试与构建：待发布 PR 验证。
- Electron 真实预习预览：已验证输入框显示、点击后自定义“东南西北”键盘出现、点击“东”后文字成功回填。
- 生成产物：已确认预习配置同时包含 `inputImg.atlas` 与自定义键盘图集。

## 已知限制与未包含内容

- 本次不执行公司台式机正式部署、服务重启或老师端分发。
- v1.3.0 Windows 安装包的真机首次安装、覆盖升级与分发验证状态沿用 v1.3.0 Release 记录，本热修复不重新验证安装包。
- 内部服务仍需运行 `pnpm dev`，不能使用静态 `pnpm build` 或 `pnpm preview` 代替。
