## 用户可感知变化

- 新增数字、小数点和分数输入键盘，支持分数输入框、结构化分数编辑和对应答案判定。
- 输入框支持多个候选正确答案，以及同一答题容器内的两框加减乘除和相等关系判定。
- 锁定图层不再阻断下方未锁定图层的画布点击命中；图层列表仍可查看和解除锁定。
- 选择题支持稳定选项答案引用，自动推导单选/多选，支持通常、按压、选中、正确、错误五态交互和正课/预习/作业判定链路。
- 快捷题型确定按钮支持本版本确认过的黄色繁体资源，并可继续在属性面板替换资源。
- 统一补齐预览课件中的 SDK 正确、错误和未完成反馈音效。

## 修复与工程改进

- 修复作业模式独立输入框的自动判定结果聚合。
- 修正黄色分数按钮的普通态和按下态资源。
- 更新 Windows 安装包工作流，使指定 Tag 的安装包可生成、校验并上传到对应 Release。

## 明确不纳入本版

- 资源库独立搜索与三级快捷筛选 `#73` 不纳入 v1.2.0，顺延至 [v1.2.1 需求基线](../roadmap/v1.2.1-requirements.md)。当前版本保留已有资源库基础搜索、目录和快捷标签能力，但不宣称完成 #73 的最终交互。
- 不新增资源库正式素材和标签映射；本版本沿用上一正式素材快照。
- 不改变课程本地数据、上传目录和用户自定义模板的存储边界。

## 已知限制与部署

- 当前内部服务仍依赖 `pnpm dev`，没有 Windows 服务守护和自动重启。
- 公司台式机必须部署本版本对应的 Tag，并沿用 v1.1.0 素材快照。
- 发布前必须确认 `v1.1.0` 安装包、素材快照和运行数据备份仍可回退。
- 未完成 Windows 实际安装验收前，不向老师分发安装包。
