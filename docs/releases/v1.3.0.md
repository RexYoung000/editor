## 用户可感知变化

### 自定义文本答案键盘

- 老师可为每个键盘实例配置 2 至 9 个文本答案，每项最多 4 个字符。
- 答案键按文本长度自动布局，优先减少行数并避免退格键单独成行。
- 支持黄色、蓝色、绿色三套皮肤；每个键盘实例独立选择主题。
- 绑定输入框后按完整答案替换内容，预览和发布前会把键帽文字与输入框字库烘焙为图片，不依赖学生设备字体。
- 发布前校验空答案、重复答案、超长答案、无效主题和正确答案缺失。

### 视频关卡来源与替换

- 正课和复习课的视频关卡支持预设视频、本地 MP4 与资源库视频三种来源；作业和专题测评支持本地 MP4 与资源库视频。
- 内置 39 个按课件类型和语言分类的正式预设视频，支持搜索、筛选和选择前预览。
- 视频先完成校验与落盘再创建关卡，取消或失败不会留下空关卡。
- 已创建的视频关卡可从属性面板更换视频；锁定关卡仍保持结构与几何不可修改。
- 三种来源统一限制为 50 MB 内 MP4，使用校验值确认下载完整性并按 MD5 去重，替换后清理未引用旧副本。

## 修复与安全

- Vite 的课件、预览、上传、静态资源与 ZIP 文件操作统一限制在各自根目录，拒绝父目录跳转、绝对路径、非法编码和空字节；PostCSS 升级至无已知生产漏洞的版本。
- 画布停止变化 500 ms 后自动更新当前关卡缩略图；折叠预习区、正课区或当前大关卡不再导致画布黑屏、选择丢失或其他页面残留。
- 右侧属性面板的文本与有效数值实时写入课件和画布；未完成数值草稿不会污染数据，连续输入仍合并为一条撤销记录。
- 自定义答案配置扩大可聚焦区域，序号、相邻空隙和输入框均可直接切换到对应答案输入。
- 新建文本显示真实默认内容“**双击编辑文本**”并保持普通选中；双击默认内容后全选替换，点击外部或清空退出不会删除组件。
- 文本编辑态使用 I-beam、独立高对比插入光标和青白辅助框，与普通蓝白选中态清晰区分。

## 兼容性与交付决定

- 本版包含向后兼容的新能力，按 SemVer 从 v1.2.2 升级到 v1.3.0，不引入破坏性课件格式迁移。
- 历史课件缺少新增字段时继续走现有默认值和兼容分支；已有文本内容和颜色不会被迁移。
- Electron 新增本地视频校验、复制、资源库下载与替换相关 IPC，因此旧客户端不能作为本版完整能力基线，老师端必须安装 v1.3.0 客户端。
- 外置 `public/builtin/library/` 不随 Git 更新，本版继续使用上一正式版本的素材快照；内置键盘和视频资源随 Tag 下发，不需要单独同步外置素材库。
- 公司台式机必须部署 `v1.3.0` Release 对应 Tag；不能直接拉取 `main` 作为正式版本。

## 明确不纳入本版

- 不新增账号、Token、权限或公网部署能力；Vite 服务仍只能运行在受控公司网络。
- 不增加新的外置资源库素材或标签映射。
- 不扩展富文本、自由键盘排版、超过 9 个答案或超过 4 字的单项答案。
- 不把静态 `pnpm build` 或 `pnpm preview` 改造成正式服务，内部服务仍需运行 `pnpm dev`。
- 不在发布 PR 中执行最终公司台式机部署、老师端分发或生产数据迁移。

## 已知限制与部署

- 当前内部服务仍依赖 `pnpm dev`，没有 Windows 服务守护和自动重启；部署机重启后需要恢复服务。
- 本版增加约 39 个源码内置视频，首次拉取代码、安装包生成和局域网首次加载的耗时需要在正式环境观察。
- macOS 开发回归和自动测试不能替代 Windows NSIS 安装版验证；`win-unpacked` 也不能替代真实安装。
- macOS 本地工程已成功导出，但测试目录不属于 SVN 工作副本，因此正式 SVN 提交链路仍需在公司目录验证。
- Windows 安装包、SHA-256、最终 Tag、GitHub Release、公司台式机部署和老师端分发必须在待执行项完成后由 Rex 操作。

## 部署与回退

- 部署前备份 `public/builtin/library/`、`public/uploads/`、`preview-server/lessons/`、运行配置和当前 v1.2.2 运行状态，不使用 `git clean` 清理部署目录。
- 服务器升级到 `v1.3.0` Tag 后安装锁定依赖并运行 `pnpm dev`，再使用 v1.3.0 Windows 客户端完成局域网验收。
- 出现阻塞老师使用、课件损坏、视频落盘失败或编译发布不可用时，服务器回退 `v1.2.2`，客户端回退已验证的 v1.2.0 安装包，外置素材库保留原快照。
