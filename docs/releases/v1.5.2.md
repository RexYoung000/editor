## 版本范围

本版是 v1.5.1 之后的紧急 PATCH，覆盖两个已在测试服复现并验证的发布问题：

- 修复作业、正课和预习模板中 `FractionInput` 初始化时同步判定值导致线上课件黑屏的问题，同时让普通数字输入也能被运行时判定识别为已填写。
- 修复老师将课件原地发布到本地 SVN 目录时，旧的根级运行产物目录（`image`、`sound`、`animation`、`res`、`bin`）残留并被继续纳管，导致最终工程结构不符合规定格式的问题。

另包含当前主线已合入的项目交接与发布边界文档整理，不改变用户数据结构。

## 用户可感知变化

- 发布到测试服或打包机后的课件可以正常打开含分数输入框的页面，不再因初始化同步空值触发 SDK 空对象写入崩溃。
- 在分数输入框中填写普通数字时，运行时判定不再把内容当作空值。
- 原地发布到已有 SVN 课件目录时，编辑器会把历史遗留的根级运行产物纳入本次受管清理，避免最终提交目录多出不属于规范工程结构的资源层。

## 客户端与服务器更新决定

- **只修复分数输入课件黑屏 / 判空问题**：更新公司服务器到 `v1.5.2` 后即可生成新模板和新前端页面，老师端关闭并重启现有客户端可加载服务器页面。
- **完整使用 v1.5.2**：必须同时更新公司服务器并安装 v1.5.2 Windows 客户端。原因是原地发布残留资源清理位于 `electron/coursePublish.cjs`，旧客户端不会获得这段本地进程逻辑。
- 本版本没有新增 Electron IPC、preload API、打包依赖或内置 SVN CLI 版本，但修改了 Electron 主进程加载的发布模块；因此正式交付按“客户端必须升级”处理。

## Windows 真机验收

安装包生成后至少完成：

1. 从 v1.5.1 覆盖安装 v1.5.2，确认服务器地址保留。
2. 连接公司服务器，打开触发过问题的 `s9_v9_05_YY_hw` 或等价作业课件，完成预览与发布。
3. 在本地 SVN 目标目录包含旧根级 `image`、`sound`、`animation`、`res` 或 `bin` 残留时，确认发布准备会清理这些受管旧产物，最终只提交身份文件和实际 `Game1_*` 工程。
4. 重新打开已发布课件，确认分数输入框填写普通数字与分数都能被判定为非空。
