## 版本范围

本版包含 v1.4.0 之后已经合入的四项产品能力：图层树折叠检索与画布选择同步、基础选择集属性与固定多选工具、百分号和手指 Spine 资源，以及老师课件发布与 SVN 打包闭环。上述变化保持现有课件数据兼容，因此按 SemVer 升级 MINOR 至 v1.5.0。

## 用户可感知变化

### 图层浏览与画布定位

- 图层树支持按运行容器和编辑器图层组折叠，展开偏好按课程和页面保存。
- 搜索可以匹配图层名称、组件标识、类型和父级路径，并临时展开命中项的必要祖先。
- 筛选支持全部、仅选中、隐藏、锁定和组件类型；搜索清空后恢复之前的折叠状态。
- 画布明确选中深层组件时，图层面板自动展开祖先并定位主选中行；画布与图层行悬停只做轻量高亮，不改变选择。
- 保留每个容器和图层组自己的展开入口，不增加全局展开/收起或画布组件/组模式。

### 多选属性与排列

- 选中两个及以上元素时，属性面板显示选择数量、主选中项、画布绝对坐标下的 X、Y、宽和高。
- 支持宽高比锁定、批量透明度、显隐和锁定；连续编辑只形成一条撤销历史。
- 选择集跨不同父容器时仍按画布绝对位置移动和缩放，保持元素之间的空间关系。
- 对齐和分布移动到画布顶部固定工具栏；窄窗口收纳为“排列”菜单，不再跟随图层列表滚动。
- 锁定或受父级锁定的成员保留在选择集中，但不参与几何、透明度和排列修改，并显示禁用原因。

### 百分号与手指 Spine 预设

- 四种现有百分比键盘改用黄、蓝、绿三套正式百分号图片；输出字符、按键布局、答案数据和判定规则不变。
- 新建和历史百分比键盘在新版编辑器重新预览或导出后使用新资源，已经发布的旧课件包不会自动变化。
- “常用组件 → Spine 动画”增加“空白 Spine”“手指点击”“手指移动”三个选择项。
- 两个手指预设分别创建独立 Spine 元素，固定使用各自的 `game_an1` 或 `game_an2`，不自动建立触发关系。
- Spine 属性中的播放操作改为单次试听，结束后回到第一帧并暂停；课件运行时仍由老师通过“播放动画”动作触发。

### 老师课件发布

- 工具栏提供连续发布窗口，依次完成最新预览确认、SVN 目标确认、完整工程生成、TortoiseSVN 提交和打包机通知。
- 普通课件根据实际内容分别确认预习和正课；作业、专题测评和复习课只确认各自实际工程。
- 老师填写 SVN 业务父目录并选择已经拉取的本地 SVN 文件夹；编辑器读取真实 SVN 元数据进行映射，不根据磁盘路径猜测地址。
- 课件已经位于最终 SVN 目录时执行原地发布，只提交身份文件和实际 `Game1_*`；课件位于其他目录时才同步完整工程到目标目录。
- 当前课件目录与目标目录互相嵌套但不相同时阻止发布，避免覆盖源课件或生成目录。
- Windows 安装包内置固定版本 SVN CLI，只用于本地工作副本检查；真正的远程提交继续打开公司 TortoiseSVN，复用已有账号、权限和 SASL 环境。
- SVN 提交成功并通知打包机后显示“发布已提交”；只有收到打包机全部完成反馈后才显示“发布成功”。通知失败时可以恢复任务并只重试通知。

## 兼容性与交付决定

- #136 修改 `electron/main.cjs`、`electron/preload.cjs`，新增发布 IPC、本地状态和 Windows `extraResources`；旧客户端没有这些能力，因此老师端必须安装 v1.5.0 Windows 客户端。
- 公司服务器与 Windows 安装包必须使用同一个最终 `v1.5.0` Tag，不能只更新其中一端。
- 不迁移历史课程数据。图层折叠、选择主项和发布绑定属于编辑器本地状态；发布身份与生成工程位于老师选择的 SVN 目录。
- 内置百分号、手指 Spine、`game.zip` 和 SVN CLI 随源码 Tag 或安装包更新；外置 `public/builtin/library/` 快照不变。
- forge 不保存 SVN 账号密码，不使用内置 CLI 执行远程提交，也不改变现有打包机内部编译、上传或部署协议。

## 已知限制与未包含内容

- 阶段一 #13 已按 `Not planned` 关闭，原定 18 步完整 Electron 端到端回归没有执行；本版本按实际变化执行最小必要回归，不宣称历史回归已经完成。
- #17 尚未在真实 300+ 图层课件上记录长列表滚动、深层画布命中与双向悬停手感。
- #136 专项测试包通过不能代替 v1.5.0 最终 NSIS 安装包的首次安装和覆盖升级验收。
- 发布窗口不替代 SVN 冲突解决工具；遇到远端更新、冲突、账号或权限问题时，老师仍需先在公司 TortoiseSVN 中处理。
- 编辑器只能展示现有打包机已经提供的状态；连接中断或没有最终反馈时保持“发布已提交”，并引导老师查看打包机反馈群。
- 内部服务仍需运行 `pnpm dev`，不能使用静态 `pnpm build` 或 `pnpm preview` 代替。
- 本次不执行公司服务器生产部署、服务重启、生产数据迁移或老师端正式分发。

## 部署与回退

- 公司服务器必须部署最终 `v1.5.0` Release 对应 Tag，并与同版本 Windows 安装包配套使用。
- 部署前保留 `public/builtin/library/`、`public/uploads/`、`preview-server/lessons/`、课程目录和本机配置，不使用 `git clean` 清理部署目录。
- 出现客户端 IPC 不兼容、安装包内置 SVN CLI 缺失、发布目标错误、课件工程异常或打包机通知无法恢复时，服务器和客户端均回退 v1.4.0。
