## 版本范围

本版是 v1.5.0 的客户端热修复，只解决 Windows Electron 连接另一台电脑提供的局域网 HTTP 服务时，点击“发布工程”无法计算课件内容摘要的问题。不修改课件数据、SVN 目标、工程结构、打包机协议或素材内容，因此按 SemVer 升级 PATCH 至 v1.5.1。

## 用户可感知变化

- 老师通过 `http://<局域网地址>:<端口>` 使用编辑器时，可以正常打开发布窗口，不再出现 `Cannot read properties of undefined (reading 'digest')`。
- 旧课件和新课件使用同一发布入口，不需要移动课件、修改 SVN 目录或把公司服务改成 HTTPS。
- 服务器页面先更新但客户端仍为旧版时，发布入口会明确提示安装最新版，不再暴露英文函数错误。

## 修复说明

- 课件文本 SHA-256 从远程页面的浏览器 Web Crypto 移到 Electron 本地进程计算。
- Electron main、preload 和渲染端使用同一 IPC 契约；发布流程不再依赖页面是否属于浏览器安全上下文。
- 新算法继续按 UTF-8 计算标准 SHA-256，与 v1.5.0 的摘要字节和 64 位十六进制格式一致，已有预览确认及发布状态无需迁移。
- 工程目录摘要、SVN 同步、TortoiseSVN 提交与打包机通知流程保持不变。

## 兼容性与交付决定

- v1.5.0 Windows 客户端没有 `publishHashText` IPC，无法仅靠服务器更新获得修复；公司服务器和老师客户端必须配套升级到 v1.5.1。
- 课件 JSON、发布身份文件和既有内容摘要格式均不变化，可以直接覆盖安装。
- 内置 SVN CLI、三色百分号、手指 Spine、`game.zip` 和外置素材库均沿用 v1.5.0。

## Windows 真机验收

安装包生成后必须在正式部署等价环境完成：

1. 电脑 A 运行 v1.5.1 Tag 对应的 Vite 服务。
2. 电脑 B 从 v1.5.0 覆盖安装 v1.5.1，并连接电脑 A 的局域网 HTTP 地址。
3. 打开触发过问题的历史课件，点击“发布工程”，确认发布窗口正常展示。
4. 至少完成一次预览确认并进入发布目标步骤，确认内容变化仍会使确认失效。
5. 重启客户端，确认服务器地址保留，发布入口仍然正常。

自动构建成功和安装包 SHA-256 只能证明产物完整，不能替代上述 Windows 安装、升级和真实发布体验验收。

## 已知限制与未包含内容

- 本版不修改公司服务器的 HTTP/HTTPS 部署方式。
- 本版不处理老师课件发布流程之外的浏览器摘要用途。
- 本次不执行公司服务器部署、服务重启、老师端分发或真实 SVN 提交。
- v1.5.1 安装包完成 Windows 真机验收前，不宣称已完成公司环境发布验收。

## 部署与回退

- 公司服务器部署 `v1.5.1` Tag，老师电脑配套安装 v1.5.1 Windows 客户端。
- 更新服务器前保留 `public/builtin/library/`、`public/uploads/`、`preview-server/lessons/` 和本机配置，禁止使用 `git clean` 处理部署目录。
- 如出现新的客户端启动、IPC 或发布异常，服务器和客户端共同回退 `v1.5.0`；回退后局域网 HTTP 发布摘要问题会恢复。
